## Bounded LP Marshal support

Marshal wire format. The new `Candle_marshal` module parses only the measured
integer, string, block, backward-reference, and legacy int64 encodings into an
explicit tree; unsupported codes, malformed lengths, bad object counts,
forward/cyclic references, and trailing bytes fail closed. The normalized LP
source then validates every expected constructor, tag, arity, scalar, list,
variant, and record field while rebuilding the typed certificate. The unused
runtime writer fails explicitly.

On a real `hard_2.dat` shard, native OCaml and Candle independently produced
the identical structural summary:


The same gate confirmed that malformed bytes are rejected. This is a focused
decoder/shape gate, not proof verification of the 39 shards; complete LP proof
execution remains the action-184 S3 gate.
