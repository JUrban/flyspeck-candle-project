## The complete numerical leaf result is now one computed verdict

The certified centered Taylor checker now has a list-level reflected boundary.
A batch job is ordinary logical data containing a certificate-only center
expression and an exact rational box. One authenticated box expression is
shared by the whole list.

The executable batch checker recursively runs the already proved centered,
outward-rounded checker for every job and returns one `cval` Boolean. Its
general correctness theorem equates that result with conjunction of every
logical numerical acceptance condition. The proof adapter authenticates the
compiled job list, makes one `Kernel.compute` call, and derives one theorem for
the whole accepted batch.

The corresponding general soundness layer proves:

```text
valid source expression
/\ every batch cell accepted
/\ every cell has the source dimension
/\ accepted cells cover the root box
==>
the source expression is negative throughout the root box
```

The cover premise is semantic and therefore cannot hide a geometric
assumption in untrusted ML. A subsequent reflected split-tree checker can
discharge it from exact root, split-axis, split-point, and leaf-box data.

During actual integration, the first run exposed an inferred-type defect: the
certificate-erasure predicate had left its otherwise unused box payload
polymorphic. The definition is now fixed to the exact rational-box type. This
was a new batch-schema defect, not a numerical or Flyspeck failure.

## What is compact now, and what remains per cell

One computed verdict now performs all of the following for every cell:

1. centered and whole-box program evaluation;
2. all analytic domain guards;
3. exact box validity;
4. outward-rounded Taylor-upper construction; and
5. the strict-negative decision.

The correctness theorem links that single verdict to all numerical cell
acceptances at once.

The current adapter still performs these operations linearly per cell:

1. propose a center certificate variant;
2. kernel-check its compiler/program encoding and exact erasure to the shared
   source expression;
3. encode its exact box;
4. project its acceptance from the batch theorem;
5. instantiate a cell source theorem; and
6. construct ordinary Flyspeck split/glue theorems.

Thus this milestone removes repeated numerical theorem executions but does not
yet produce one compact root theorem. The next bounded proof step is an exact
data-level split-tree/topology checker plus its general coverage theorem. The
first target should be this same two-child leaf: use the existing batch
soundness theorem once at the root, then perform one Flyspeck source handoff.
Only after that is green should the experiment expand to the existing
four-leaf representative batch, charging source and tree preparation once and
comparing it with the 128--129 second certificate-variant baseline.

The per-cell erasure and compiler checks should also be measured at that
boundary. If they dominate on a larger batch, their structural relationships
can be checked as batch data under one general theorem; no new analytic
architecture is required for that extension.
