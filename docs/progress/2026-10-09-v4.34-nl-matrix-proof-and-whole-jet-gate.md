## Next whole-jet native gate

The next native experiment is deliberately coarser than dispatch fusion or a
single elementary operation.  It will use the authenticated 167-instruction
fifth-sibling program and the already captured genuine forest, while holding
the scalar backend and final contract fixed.

The candidate will maintain two numerical data states for each authenticated
source node:

- a center value and center gradient; and
- a whole-box value, gradient, and symmetric Hessian.

It will reuse the current exact `2^40` checked arithmetic, directed quotient
rounding, square-root certificates, fixed arctangent, historical dihedral
formulas, box endpoints, and final Taylor completion.  The only changed axis
is propagation cadence: interval jet composition happens directly over the
box and the complete expression is Taylor-completed at the declared boundary,
rather than constructing a theorem-shaped completed Taylor result after every
generic source operation.

The implementation should reuse the existing `FirstJet`, `SecondOrderBox`,
polynomial-jet, and source-DAG authentication machinery.  It must not dispatch
on a basename, outer index alone, or an unauthenticated formula alias.  The
first run is an untrusted native discriminator, so no proof work begins until
the following gates pass:

1. On the fixed historical path, all 1,344 reached nodes preserve domain
   outcomes and all 682 negative pruning decisions.  Record bound deltas, not
   only pass/fail.
2. From the genuine initial box, the candidate accepts the complete
   certificate with no more visited nodes, rejected leaves, or maximum depth
   than the current historical route.
3. Report source/program preparation, recurring fixed-node evaluation,
   root-started traversal, total elapsed time, and peak memory separately.
4. Run balanced repetitions, charge reusable preparation once in the batch
   comparison, and retain exact result/decision streams for audit.
5. If loss of intermediate Taylor tightening reproduces the earlier
   408/875-style coverage failure, stop this candidate.  Do not patch it with
   source-specific exceptions; instead retain completions only at a generally
   characterized nonlinear or reuse boundary and rerun the same gate.
6. Only a material complete-search winner proceeds to the padded-hardware
   cross, which isolates arithmetic representation under the new propagation
   design.  A second genuine expression family is required before enlarging
   the general proof surface.

This experiment directly tests generic derivative/Taylor work while keeping
arithmetic and rounding fixed.  The subsequent exact-versus-padded cross keeps
the winning mathematical route fixed while changing representation.  Together
they provide the requested held-axis plan for the larger remaining gap.
