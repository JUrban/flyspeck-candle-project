## The repeated source proof was unnecessary

The v1.82 profile showed that the centered `Kernel.compute` evaluation was not
the dominant cost. For every attempted child box, the proof adapter rebuilt a
point-specific analytic AST, re-proved its equality to the original Flyspeck
formula, compiled it, encoded it, and only then ran the numerical checker.

Only the square-root certificate fields differ between a point program and
the already authenticated box program. The universal Taylor-model theorem
requires:

- a valid authenticated box expression;
- exact equality after erasing square-root certificates;
- the compiled point and box programs; and
- certified numerical acceptance.

It does not require a second proof from every point expression directly to the
original surface formula. The box expression already supplies that source
theorem.

A new lightweight certificate-variant path therefore:

1. traverses the original source only to propose point square-root intervals;
2. replaces certificate fields in the authenticated box AST;
3. kernel-reduces the variant compiler and program encoding;
4. checks exact certificate erasure against the box AST; and
5. uses the unchanged universal soundness theorem and box source theorem to
   derive the final Flyspeck result.

Variant construction and floating endpoint proposals remain untrusted. A
wrong AST shape, unused/missing interval, source-function mismatch, erasure
mismatch, compiler mismatch, domain failure, changed source conclusion, or
theorem assumption fails closed. The original full-preparation adapter remains
available for independent comparison.

## Remaining per-child work and next boundary

The current path still constructs a compiler equality, encoded-program
equality, computed evaluation equality, and child negativity theorem for every
accepted box, then explicitly glues child theorems. The approximately
4.9-second pre-compute interval per attempt remains the largest recurring
component.

The next bounded architecture step remains a data-level certificate-tree
checker. It should accept one authenticated source AST plus certificate-only
variants, boxes, centers, and split nodes as ordinary data; validate all
erasure, domain, coverage, and verdict conditions computationally; and apply
one generally proved tree-soundness theorem at the original root. The variant
result demonstrates that source correspondence can safely be paid once and
provides the representation boundary for that checker.

The same four leaves are the correct first target: a compact tree result must
produce the same four root theorem digests and beat the 128--129 second variant
baseline before expanding the sample.
