## What changed

CakeML commit `3b1f875aa` adds the two layers above the generic packed checker
from v4.229.

The first layer is a generic source compiler.  It:

- turns every source rational `(positive-negative)/(denominator predecessor+1)`
  into an outward fixed interval at scale 2^40 using exact natural arithmetic;
- rejects an endpoint that cannot fit word64;
- checks every variable against the supplied dimension;
- recognizes the six proved delta instructions only by exact source-program
  equality; and
- otherwise compiles the general polynomial, square-root, inverse, arctangent,
  and arithmetic instruction language.

This removes the finite case-16594 constant table from the general path.  A
closed theorem shows the new compiler produces the complete existing
167-instruction case-16594 prepared program exactly, including the same six
specializations.

The second layer is strict versioned plan metadata:

```text
Pair (Num 1) (Pair (Num dimension) (Num cell_count))
```

Only version 1 is accepted.  Dimension and cell count must be positive and
fit the 32-bit wire fields.  Certificate count is deliberately not supplied
by the caller: it is derived from the checked prepared program, closing the
short-record alias that a free count would create.

The complete pure path is now:

```text
source cv
  -> fail-closed source decoder
  -> generic checked preparation
  -> derived certificate count
  -> program/dimension/count-parameterized packed checker
```

For the genuine case-16594 source CV and metadata `(1,6,875)`, HOL proves this
path is exactly equivalent to the established complete 875-cell checker.
