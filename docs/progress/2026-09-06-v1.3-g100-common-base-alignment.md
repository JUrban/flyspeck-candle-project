Date: 2026-09-06 UTC

## Scope and status

This report covers only the common HOL base needed by G100-S.  It does not
claim a representative target state match, G100-S, S1, or release authority.

The approved HOL Light reference loads `thecops.ml`.  Candle's default base
had omitted that file and, before `eabe9a6`, loaded the optional
`candle/compute.ml` extension.  The selected 400-source parser inventory has
been mechanically searched for the optional `cval`/`Cexp`/`Kernel.compute`
API: no consumer was found outside the optional extension itself.

  declaration and primitive-definition multisets are structurally equal.

serializer contract still observes implementation-dependent generated names.
No exact-state claim is made from alpha-equivalence.
