## Remaining correspondence boundary

The new theorem is the universal analytic reference contract. It does not by
itself prove that every interval returned by the tighter optimized historical
gradient and Hessian formulas encloses these same components. In particular,
the generic interval composition has previously been too loose on most of the
4,173 genuine boxes, so its acceptance set must not be substituted for the
specialized checker.

The next proof boundary is therefore the faithful one:

1. instantiate the exact delta-x4, supplied root-delta, and supplied
   root-four-x0 component contracts;
2. prove the specialized historical `b`, gradient, logarithmic-U, and final
   Hessian formulas enclose the corresponding universal components;
3. connect that theorem to the actual executable second-order result; and
4. rerun the unchanged 4,173-cell checker via direct `./cake`, measuring
   preparation, compilation, execution, theorem/verdict handoff, total time,
   and peak memory separately.

Only that matched specialized run will be described as a complete
proof-connected historical-dihedral checker measurement.
