## Reflected reciprocal above the shared-jet evaluator

The first dimension-generic analytic jet constructor is now complete. Given
an input interval jet and a value interval that excludes zero, the reflected
program computes the reciprocal value, gradient, and Hessian entirely as
data:

```text
D(inv f)  = -(inv f)^2 Df
D2(inv f) = -(inv f)^2 D2f + 2(inv f)^3 Df (x) Df
```

The implementation reuses the normalized interval-list, interval-matrix, and
outer-product operations from the polynomial shared-jet evaluator. It does
not generate 43 separately expanded derivative programs. The exact domain
decision is computed from the input value interval, and a zero-crossing
interval cannot authorize the semantic theorem.

The new reusable component contract states that a jet encloses a real value,
every gradient component, and every Hessian component. The aggregate
reciprocal theorem proves that a shaped input jet satisfying this contract
and the nonzero domain condition produces a jet satisfying the corresponding
reciprocal value/gradient/Hessian contract. The cval transformer has exact
representation theorems for the transformed jet and its domain decision.

This is the semantic machinery required for an `inv` analytic-expression
node. It is not yet the generic analytic AST/reifier or a complete
action-296 formula check.

## Checkpoint policy and next boundary

Candle commit `cc3686c47c12d2b4dd5dd883db80fd3d6bf54541` records the
reciprocal-jet implementation and regression.

The existing support-only checkpoint remains the best editing boundary: the
new reciprocal layer loads and proves in about 25 seconds, so a second
checkpoint here would add management and invalidation cost without saving a
material reload. It should instead remain a post-checkpoint overlay while the
generic analytic AST/reifier and the next analytic primitives are changing.
The boundary can move forward after those pieces form a stable, substantially
more expensive reusable stage.

The next implementation boundary is to connect reciprocal to a composed
analytic source AST/reifier, then add the guarded square-root jet primitive.
Arctangent and a checked interval enclosure of `pi` remain necessary for the
full authenticated action-296 source and integrated certificate comparison.
