- Candle was built from the pinned CakeML binary and loads both `pft.ml` and
  the modified `replay.ml`.
- HOL4's core system and standard theories built with `-j 4` far enough to
  produce `bin/hol`; all eleven official PFT writer self-tests pass.
- HOL4's help-index phase attempted to invoke GNU Parallel beyond the requested

  `OCAMLPATH=/usr/lib/ocaml`.  A full `hol.ml` initialization completes and a
  checked `REFL` theorem is produced.  An earlier marker-only smoke command is
  explicitly not counted because startup had failed before the marker.

## Re-evaluation and open Gate 1 risks

The immediate next target is no longer basic protocol alignment; it is an
auditable endpoint contract.  Four items are required before calling Gate 1
closed:

1. Generate/replay a representative preamble and exercise every permitted PFT
   command, especially definitions, specifications, and compute commands.
2. Replace the callback-only axiom control with an exact, portable release
   allowlist and report every axiom actually consumed.
3. Return deterministic theorem identities, hypotheses, trace identities, and
   resource counters from replay rather than relying on console output.
4. Recompile the modified endpoint and state precisely which CakeML/Candle
   theorem covers that compiled artifact.

The current footer implementation also performs two sequential passes over a
trace.  It removed unsafe shelling and side files, but it is not the final
large-trace design; Phase 3 needs seek/index support or an equivalent bounded
streaming construction.
