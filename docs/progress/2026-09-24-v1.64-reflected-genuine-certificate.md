## The 43-program expansion is not part of the selected architecture

The genuine-leaf experiment reported in v1.62 used 43 separately expanded
programs only to test the older explicit-derivative checker boundary:

```text
1 source + 6 first derivatives + 36 second derivatives = 43 programs
```

That route was a negative comparison.  It is not required by the shared-jet
checker and does not justify a new smart-symbolic-differentiation layer.

The same captured source formula and all 16 authentic leaf boxes have now been
run through the intended shared-jet path.  The source is reified and compiled
once to one **87-instruction program**.  Its value, gradient, and Hessian
enclosures are then computed together for each box.  The universal
`candle_q_dim_poly_jet_whole_box_accept_sound` theorem converts each accepted
result into a strict real bound over the original source expression.

## Performance interpretation

The prior leaf-only batch took 72.72 seconds from the same universal
checkpoint, including 62.547 seconds of support loading and 9.531 seconds for
all 16 recurring leaf checks.  The complete certificate run took 100 seconds,
so endpoint adaptation plus the 15 glue proofs added approximately **27.3
seconds** in this comparison.

This first complete reflected certificate is not yet a speed win over the
approximately 34-second legacy run from its richer close checkpoint.  The
checkpoint preparations differ, so the cold totals are not strictly
apples-to-apples; after subtracting the reflected support load, its measured
recurring work is about 36.8 seconds, close to the legacy one-certificate
baseline.  The important architectural result is that numerical evaluation,
derivatives, Taylor bounding, theorem handoff, and final certificate assembly
all succeed without the 43-program expansion or per-expression calculus
proofs.

The remaining local cost is theorem handoff and endpoint/glue reconstruction,
not shared-jet numerical evaluation.  That work should be profiled and reduced
before judging batch throughput over many inequalities.

## Decision and next boundary

Smart symbolic differentiation remains deferred.  The selected path is now:

1. integrate the shared-jet leaf callback and split/glue adapter with the real
   certificate driver rather than a captured standalone tree;
2. profile and reduce repeated endpoint/component proof construction, charging
   reusable preparation once;
3. run a small batch of complete genuine inequalities through the integrated
   path; and
4. broaden source-language and analytic coverage only when an actual verifier
   expression requires it.

This closes the bounded milestone of one complete small real inequality with
certificate coverage and final theorem assembly.  It remains non-release
development evidence while the protected direct Flyspeck run continues.
