## Guarded reflected square-root jet

The reflected analytic path now has a dimension-generic square-root
transformer for complete value/gradient/Hessian interval jets. An untrusted
preparer supplies a rational interval `s` intended to enclose `sqrt(f)`. The
already committed endpoint checker authenticates that interval by exact
nonnegativity, ordering, and squared-endpoint comparisons. The transformer
then uses

```text
d  = 1 / (s + s)
dd = -1 / ((s + s) * (f + f))
```

and checks both inverse denominators before accepting the certificate. The
generic kernel theorem proves the standard square-root chain rule for every
dimension and every child jet satisfying the component contract. The cval
implementation has representation theorems for the complete jet and for the
domain decision.

The focused exact-point regression uses `f = 4`, gradient `1`, Hessian `0`,
and `s = 2`. It checks the complete result

```text
value      2
gradient   1/4
Hessian   -1/32
```

It also rejects a false enclosure `s = 3` and rejects the zero-input case
where the derivative denominators are invalid. The accepted computed domain
decision is transported through the cval correctness theorem to the ordinary
logical domain proposition; the semantic result is not reconstructed by
unfolding the bounded rational normalizer.

## Source-integrated square root

The bounded source bridge now accepts a top-level square root of a polynomial
child. The test source `sqrt (&4 + x)` is handled as follows:

1. the theorem-producing polynomial reifier authenticates `&4 + x` and emits
   its three-instruction postfix program;
2. the compact shared-jet evaluator computes the child value, gradient, and
   Hessian once;
3. the guarded square-root transformer checks `s = 2` and computes the
   complete transformed jet; and
4. generic source and semantic theorems connect the result to the original
   HOL expression.

This uses one shared child program, not separately expanded programs for the
value and every derivative. The source-correspondence theorem, computed jet,
computed domain acceptance, and semantic theorem are all assumption-free.
