## The center is now first-order data

The authentic 16-leaf comparison in v1.77 isolated a repeated cost that the
polynomial shared-jet checker did not pay: the analytic checker constructed a
full Hessian both at the center and over the box, although the Taylor upper
bound uses only the center value and gradient.

A new general first-order analytic interpreter now covers every constructor in
the currently supported reflected language:

- polynomial nodes;
- negation, addition, multiplication, and square;
- reciprocal with its domain guard;
- certified square root with its domain guard.

Its universal representation theorem proves that, for every compiled analytic
program and interval environment, the returned domain flag, value, and
gradient are exactly the corresponding projection of the established analytic
jet semantics. The checker now uses that interpreter at the center and retains
the existing full analytic jet over the box. Its correctness theorem has the
same numerical-acceptance and Taylor-upper conclusion as the old checker, so
the universal analytic Taylor soundness theorem and final source theorem
interface are unchanged.

## Checkpoint reuse now follows exact source identity

The clean prerequisite boundary remains the sealed post-driver checkpoint:

```text
/project/flyspeck-candle-runs/cv-nonlinear-analytic-driver-checkpoint-v1
```

It contains the expensive stable analytic checker, prepared prover, and live
certificate driver, but not behavioral tests. The new support, checker adapter,
and prover were loaded into fresh disposable copies for every experiment; no
failed or partially loaded state was reused.

The matched-run wrapper previously treated the presence of a source path in a
checkpoint manifest as sufficient. It now requires the exact current SHA-256
record for every dependency. A changed dependency is overlaid from the nearest
compatible checkpoint instead of being silently assumed present. The isolated
first-order regressions use the earlier analytic-checker checkpoint when the
post-driver source identity is superseded. This both preserves the completed
Taylor work and makes dependency changes explicit.
