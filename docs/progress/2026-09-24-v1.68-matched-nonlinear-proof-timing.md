## Consequence for the optimization plan

The shared-jet architecture is correct and substantially cleaner than the
43-program derivative expansion, but it is not yet a speed win on this small
genuine polynomial certificate. Smart symbolic differentiation remains the
wrong response: it would return to the superseded 43-program architecture.

The preceding phase profile localizes the recurring reflected overhead to a
mixture of numerical evaluation and per-leaf theorem/representation plumbing.
The next bounded performance experiment should therefore test whether several
already-authenticated boxes for one prepared program can share a lower-level
computed result and one generic soundness bridge. It must remain below the
current Candle translation boundary and compare complete proof time, because
the earlier high-level monolithic checker was not a valid compute expression.

That batching experiment should be abandoned quickly if list/result theorem
construction grows faster than the saved calls. The genuine 1,554-instruction
`cayleyR6u` preparation profile remains a separate cold-cost target, and the
action-296 square-root/`dihatn_x` source remains the first justified language
extension. Neither requires another differentiation layer.
