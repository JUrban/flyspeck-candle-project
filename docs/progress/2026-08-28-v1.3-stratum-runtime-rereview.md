# Compiled stratum runtime re-review — 2026-08-28

## Outcome

An independent read-only review of the first compiled cumulative runner at
Candle commit `c5ede8af32104be16d7c8bdbd2e683ae811c6557` found seven material
gaps.  The findings were valid for that exact historical commit.  Rechecking
them against current integration commit
`7211fb1c95a8da60bb0d78812a31a7bf46af232c` shows that all seven have since
been closed in the runner or its in-process harness:

1. The runtime no longer trusts a self-consistent stored plan.  It reconstructs
   the complete plan and every prefix from the pinned manifest, source graph,
   full driver, normalization overlay and generated inputs, then requires exact
   object and byte equality.
2. The runtime emits the exact ordered 39-entry
   `candle_flyspeck_lp_certificate_files` list.  The setup fails closed on its
   cardinality and authenticates the underlying generated inputs.
3. Preflight, per-action, boundary and fingerprint success records are exact
   whole lines carrying a fresh 128-bit attempt nonce.  Quoted source text and
   duplicate, missing or reordered records are rejected.
4. Each attempt executes from a read-only attempt-local snapshot.  The linked
   executable, host plan, snapshot and control inputs are reauthenticated after
   execution before the receipt can succeed.
5. The in-process harness records every action's exact loader-ledger transition,
   distinguishes load and skip outcomes, enforces order and rejects unexpected
   ledger changes.
6. Process-group termination and reaping are in `finally` cleanup, while the
   final receipt is written atomically as completed or failed.
7. Wall time is supplemented by child CPU, address-space and output-file
   limits, with child resource use retained in the receipt.

The closing implementation is principally in commits `d5f831e`, `379a836`,
`472f3e6`, `c50a410` and `638dfe6`.  The current 109-test host suite passes.

## Remaining gate

This review does not promote any execution to S2 or S3.  The linked verified
CakeML/Candle artifact is still being built, so the compiled boundary attempts
and the required reference-versus-Candle semantic fingerprint differentials
have not yet run.  PFT and the old Candle Great100 binary remain diagnostic
oracles only.
