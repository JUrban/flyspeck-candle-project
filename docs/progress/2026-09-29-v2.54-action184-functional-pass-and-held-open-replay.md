## Post-completion checkpoint race

The exact-marker monitor reported that action 184 exited before its marker,
but that report is contradicted by the authenticated current prefix above.
The failure was in run control:

1. the restored process read from a finite regular file;
2. after printing the final theorem, action ledger, and cumulative marker, the
   REPL reached stdin EOF and exited;
3. this occurred between the monitor's two-second polls; and
4. after process exit, `fresh-resume-log.sh` could no longer read the saved
   stdout descriptor position, so the monitor could not recognize the marker
   that was already present.

No post-action checkpoint was written, and actions 185--296 were therefore
not launched. This is a checkpoint-handoff defect, not an LP theorem or
Flyspeck source failure.
