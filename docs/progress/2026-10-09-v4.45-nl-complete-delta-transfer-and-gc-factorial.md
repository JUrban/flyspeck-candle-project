## Generational-GC discriminator

Recompiling the unchanged translated programs with `--gc=gen50000` preserves
all accepted and rejected results while changing only the generated runtime
collector.  Six alternating 25-process checker batches and six alternating
50-process checker/control batches gave:

| Executable | Wall per process | CPU per process | Peak RSS |
|---|---:|---:|---:|
| Default simple-GC checker | 0.240800 s | 0.240667 s | 241,024 KiB |
| `gen50000` checker | **0.094900 s** | **0.094967 s** | **15,232 KiB** |
| `gen50000` parse control | 0.037200 s | 0.037267 s | 14,336 KiB |
| `gen50000` subtracted check work | **0.057700 s** | **0.057700 s** | -- |

The complete checker improves by **2.54 times**, while peak RSS falls by
about **15.8 times**.  After matching the parse/runtime mode, the checked
delta work is only about **1.54 times** the native checked-192 arithmetic
counter.  Much of the former compiled/native delta gap was therefore
allocation and collection behavior, not the bounded arithmetic itself.

A rotated nursery sweep confirms the direction:

| Nursery | Wall per process | Peak RSS |
|---|---:|---:|
| 1,000 words | 0.248700 s | 30,464 KiB |
| 5,000 words | 0.128000 s | 20,608 KiB |
| 50,000 words | 0.095600 s | 15,232 KiB |
| 500,000 words | 0.095200 s | 20,608 KiB |

The final difference between 50,000 and 500,000 words is below a meaningful
decision threshold, while 50,000 uses less memory.  `gen50000` is therefore
the selected development default for this checker family.

## Consequence for the larger nonlinear plan

The bounded-word/executable route has passed its full-batch operation gate.
There is no evidence for another delta-specific arithmetic rewrite: the
remaining parse-subtracted execution gap is about 1.54 times, not orders of
magnitude.

The next matched numerical target should include the substantial historical
work still absent here: supplied roots, quotient/inverse, arctangent, full
gradient and Hessian assembly, and Taylor completion.  It should use the
same genuine boxes, retain exact output and acceptance comparisons, compile
with the selected generational collector, and keep the universal analytic
handoff separate.  This tests the actual numerical/jet architecture rather
than optimizing an already-near-native delta block.
