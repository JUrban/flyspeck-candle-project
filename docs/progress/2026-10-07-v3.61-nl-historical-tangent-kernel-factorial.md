The preparation number is conservative for the root handoff: the diagnostic

The recurring measurement excludes root calculation in both native and
Candle lanes. Each native batch performs 14,848 interval products, 58,880
endpoint products, and 128 arctangent evaluations, with zero evaluation-time

times** slower. This is a boundary-specific ratio, not a replacement for all
earlier measurements. It does show that the old approximately 15-times
encoded/native observation was not an upper bound once the genuine derivative
graph was moved.

For context, the complete native historical lane on the same 128 boxes,
including preparation, tangent, Hessian, and Taylor result, reports 0.2310
seconds and accepts 128/128. It cannot yet be compared directly with this
first-order Candle run because the Hessian and completion boundaries differ.

## Interpretation of the two larger gaps

The broader factorial remains active rather than collapsing into one
specialization proof:

1. Previous native controls assign only 1.628 times to exact-int128 versus
   padded-double arithmetic on the optimized direct graph.
2. Holding padded-double arithmetic fixed assigns only 1.087 times to the
   tested generic-versus-direct data-flow change.
3. The present same-formula, same-rounding, exact-output comparison assigns
   33.6 times at the encoded first-derivative boundary.

The original roughly 340-times generic-native/specialized-C++ observation
therefore remains a useful description of the starting architecture, while
the optimized untrusted native plan has already reduced its numerical side to
a small factor on this fixture. The dominant unresolved risk is transferring
a low-work exact checker into proof-producing execution without recreating
large `cval` rewrite/allocation costs.

The current first-order source is retained as executable development evidence
and as machinery for the complete test. It does **not** yet earn a standalone
soundness theorem or production dispatch.

## Bounded next gate and larger-gap plan

The next step is the historical box Hessian on 16 and then 128 genuine boxes.
It will reuse the exact native stage records and initially retain sealed root
intervals. The gate requires exact value, gradient, and 21 symmetric Hessian
intervals, closed theorems, measured computation/handoff, and complete
certificate acceptance once Taylor completion is attached.

If that complete 128-box route wins materially, the sequence is:

1. move root validation/calculation inside the computed checker;
2. compare the existing explicit `cval` graph with one compact, generally
   specified angle/centered-jet instruction while holding arithmetic and
   outputs fixed;
3. run all 4,173 boxes with preparation, evaluator, handoff, memory, bounds,
   and acceptance separately charged;
4. require a second expression/certificate family; and only then
5. prove one reusable instruction/checker soundness theorem plus source
   correspondence under the universal analytic bridge.

A Hessian route that is not a material complete-batch winner stops this proof
line and redirects representation work before more analytic lemmas are added.
This keeps the specialization bounded while pursuing the orders-of-magnitude
objective at the measured boundary.
