## Source-only box plan

The existing center-hint path compiles each of the seven square-root argument
expressions once into an untrusted rational program. Whole-box preparation was
still walking and classifying the original HOL term again for every box.

The new path executes those same source-only programs over exact rational
intervals. It deliberately accepts exactly the old whole-box arithmetic
fragment:

- constants, variables, negation, addition, subtraction, multiplication, and
  squaring are supported;
- division, inverse, and non-square powers fail closed; and
- all resulting endpoints remain untrusted hints authenticated by the existing
  reflected stable-batch checker.

No theorem statement, checker definition, source theorem, qualified artifact,
or accepted axiom changed.
