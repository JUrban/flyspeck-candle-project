# v1.3 S3 Phase 0 baseline — 2026-08-27

## Frozen claim

The governing target is S3.  A production run must start from the pinned
Flyspeck source and generated inputs, execute them through the Candle OCaml
frontend and verified CakeML/Candle stack, check the complete nonlinear and LP
evidence in that run, and produce the theorem

```text
import_tame_classification ==> the_kepler_conjecture
```

under exactly `ETA_AX`, `SELECT_AX`, and `INFINITY_AX`.  HOL Light runtime, a
PFT producer, and unchecked theorem import are forbidden production
dependencies.  The Isabelle classification remains the explicit S3 premise;
removing it is S4.

The full PFT run remains active as a hostile-input checker and differential
oracle.  Its identically stated theorem is not an S2/S3 completion artifact.

## Resource envelope

The user-authorized interactive ceiling is below ten CPUs and approximately
60--80 GiB RAM.  The PFT producer and sequential Great 100 runner currently use
two heavy cores and about 28 GiB combined.  Each parallel audit stream is
limited to one CPU and modest memory, leaving headroom for diagnostics.  Heavy
proof builds or additional Great 100 workers require a fresh measured check.

The roadmap's developer and small-CI profiles remain target budgets rather
than claims.  Current measurements already show that the unoptimized Great 100
runner's 6 GiB heap fits the developer memory cap per worker, while the PFT
producer is a scale-qualification workload and is not used to set the direct
source fast-lane budget.
