## Resource envelope

The user-authorized interactive ceiling is below ten CPUs and approximately
60--80 GiB RAM.  The PFT producer and sequential Great 100 runner currently use
two heavy cores and about 28 GiB combined.  Each parallel audit stream is
limited to one CPU and modest memory, leaving headroom for diagnostics.  Heavy
proof builds or additional Great 100 workers require a fresh measured check.

The roadmap's developer and small-CI profiles remain target budgets rather
than claims.  Current measurements already show that the unoptimized Great 100
runner's 6 GiB heap fits the developer memory cap per worker, while the PFT
producer is a scale-qualification workload and is not used to set the direct
source fast-lane budget.
