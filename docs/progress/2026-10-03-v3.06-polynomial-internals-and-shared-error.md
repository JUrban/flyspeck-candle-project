## Internal polynomial-class probe

The v3.05 probe attributed essentially all measurable fixed-class cost to the
22 compiled polynomial pushes. The new probe repeats selected instructions
*inside* those authentic polynomial programs before executing the unchanged
instruction. It separates:

- constant and variable leaves;
- negation and addition; and
- multiplication and square.

The matched controls use the established polynomial evaluator directly. The
duplicate path uses the same established step function, discards the selected
first result, and then executes the unchanged step. All calls use the same 128
authenticated case-10173 cells.

Negation/addition is the largest aggregate internal class in this source.
The three increments sum to 13.692 seconds, above the 9.776-second coarse
polynomial increment from v3.05. They are not an additive profile: each fine

and duplicated work changes allocation and GC. The reliable conclusion is
the within-class ordering, not a percentage partition of total time.

Every call accepted all 128 cells, returned a closed result, and left the axiom

## Exact shared-error candidate

Inspection of the fixed-scale completion path found two repeated computations:

- each Hessian-row radius was evaluated separately for the lower and upper
  gradient-bound endpoints; and
- the complete Taylor error radius was evaluated separately for the lower and
  upper value-bound endpoints.

The isolated candidate passes each radius once to a small symmetric-interval
constructor. Candle's call-by-value evaluator therefore computes the cval once
and reuses it for both endpoints. The established production definitions and
proof path were not changed.

The matched whole-checker result on the same 128 cells is:

| Mode | Run 1 | Run 2 | Mean |
|---|---:|---:|---:|
| Established current evaluator | 22.165 s | 19.637 s | **20.901 s** |
| Shared-error candidate | 21.561 s | 18.731 s | **20.146 s** |

The candidate is **0.754 seconds faster**, a 3.61% reduction or 1.037x
speedup. Both paired orderings favor the candidate, but the change is small
relative to between-run variation and to the required whole-workload gain.

A separate reflected comparison computed both complete Taylor results for
each cell and required structural cval equality. It passed all **128 / 128**
cells in 41.898 seconds. Thus this fixture establishes exact output equality,
not merely equal acceptance. All candidate checks were closed, accepted the
same batch, and added no axiom. Peak sampled RSS again remained 17,982,344
KiB.

## Decision

The shared-error change is retained as a clean measured prototype, but is not
integrated into the proved production evaluator now. A roughly 3.6% local
gain does not justify diverting the functional lane into another production
soundness and integration cycle while full direct S2 and the higher-leverage
nonlinear preparation/checker work remain open.

The experiment also explains only a small part of the 6.242-second repeated
negation/addition increment. The more consequential polynomial question is
whether complete value and gradient reconstructions can be avoided at
intermediate nodes while preserving enclosure tightness, performing them only
where a later operation or the block boundary actually needs them. That is an
architectural/dataflow candidate and must first be tested on exact results and
certificate coverage; simply loosening intermediate bounds is not acceptable.
