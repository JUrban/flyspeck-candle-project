## The numerical path now uses the one-program shared-jet architecture

The genuine action-296 leaf has now been run through the compact path proposed
in `cv_compute_polynomial_expr_dim_jet_check.ml`: one authenticated compiled
source program is evaluated at the center and over the box. The new model does
not create the 43 separately expanded value, gradient, and Hessian programs
used by the earlier derivative comparison.

Each stack node carries:

- the value and gradient at the box center;
- a Hessian enclosure over the whole box; and
- cached whole-box value and gradient bounds reconstructed by centered Taylor
  estimates before analytic composition.

Polynomial subprograms use the same centered model. Rational growth is bounded
by outward rounding after every high-level instruction to denominator
`10^12`. The program also emits the exact domain guards used by every analytic
instruction, so numerical acceptance and guard coverage are checked in one
reflected traversal.

This is the intended shared-jet route; a new symbolic differentiation layer is
not currently justified.
