## Action and identity contract

The loader preflights 399 selected source files, then installs their exact
original-path to HOL Light `(basename, MD5)` identities once.  A new static
action resolves the authenticated original path, selects only an independently
authenticated normalization registered for that exact path, evaluates the
source once, commits the logical original identity, and evaluates
`State_manager.neutralize_state ();;` once.  A duplicate performs neither
evaluation nor neutralization.

The completion marker occurs only after source evaluation, identity commit,
and neutralization all succeed.  Missing identity configuration, unknown
sources, malformed or embedded directives, source failure, neutralization
failure, and overlay reconfiguration all fail closed; later phrases in the
loaded driver are flushed.  The normalized physical path is never used as the
logical HOL Light source identity and the overlay directory is never inserted
into `load_path`.

## Evidence and open gates

Thirty-three manifest/normalization tests pass.  Compiled gates pass for exact
static-library selection, filename behavior against OCaml 4.14.1 edge cases,
accepted and duplicate source actions, overlay selection, identity and overlay
reconfiguration rejection, malformed directives, evaluation failure,

`loadt` phrases and the legacy dynamic helper definitions in strictbuild need

historical phrase-start defect also remains open.  After those are closed, the
loader must continue through every later source frontier, reach nonlinear and
LP leaves, produce semantic fingerprints and deterministic checkpoints, and
complete two clean matching runs plus one matching resume run.
