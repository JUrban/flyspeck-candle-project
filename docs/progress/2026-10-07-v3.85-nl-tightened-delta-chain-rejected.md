## Bounded follow-up to the domain failure

The rejected v3.84 whole-chain screen used a raw quotient box which crossed
the fixed arctangent kernel's `(-1,1)` contract.  The narrow follow-up kept
the already authenticated `-d(delta)/dx[j]` and `4*x[i]*delta` preparation,
then restored Taylor completion at the inverse-root and quotient boundaries.

That tightening alone was insufficient: the first genuine cell still had a
completed quotient lower endpoint below `-1`, and a later genuine center also
left the unit interval.  The native diagnostic therefore added the standard
arctangent reciprocal range reduction for center endpoints outside the unit
interval.  The polynomial arctangent kernel itself still receives only an
argument of magnitude below one.  Exact endpoints `+/-1` remain fail-closed.
The box is used only for the globally valid derivative identities
`1/(1+x^2)` and `-2*x/(1+x^2)^2`; it is not passed to the polynomial value
kernel.

This is diagnostic native code only.  The range-reduction and derivative
containment statements would require general proofs before they could become
authoritative.

The native factorial on this second genuine family already holds the two
main axes separately:

- with exact mixed arithmetic fixed, authenticated analytic lowering improves
  the generic radicand lane by 1.473 times and the complete numerator/radicand

175 times between the 225.8-second reflected batch and the 1.293-second exact
native accepted candidate.

## Bounded next plan

1. Do not pursue another whole-chain fusion until a native enclosure method
   preserves all 875 certificates.  In particular, do not prove the rejected
   range-reduced implementation.
2. Keep the analytic proof packet limited to the reusable, coordinate-
   parameterized delta derivative and `4*x_i*delta` identities and their
   universal-jet containment connection.
3. Complete the independent verified-word product-plus-dyadic-shift
   benchmark.  It holds the numerical algorithm and exact outward rounding
   fixed while changing the execution representation at the actual endpoint
   boundary.
4. If that gate remains within the tenfold complete-batch budget, extend it
   only to the measured signed 128/192 operation trace: interval sign dispatch,
   directed shifts, addition, narrowing, explicit overflow, and exact
   fallback.
5. Make the all-875 theorem-producing batch, including conversion,
   preparation, computation, handoff, acceptance, and memory, the decision
   point.  Confirm any winner on a second expression family.

The next cheap native algorithm experiment, after the executor gate, should
target a tighter quotient enclosure rather than merely delete completions.
It must compare bound quality before timing and stop immediately if complete
certificate acceptance falls.
