## Preflight overflow found and contained

The first attempted exact-native lane used `__int128`.  It failed closed on
cell zero at outer instruction 36, square-root slot 2.  Diagnostics showed the
correct center radicand near 5088.88 but an impossible whole-box enclosure near
62--77.

This was fixed-width overflow in generic Taylor recomposition, not a source,
certificate, or formula mismatch.  At scale `10^12`, the naive generic
intermediate multiplies a scale-squared factor by an already scaled value and
can exceed signed 128-bit range.  The exact control was therefore changed to
unbounded `mpz`; the overflowing run is preserved as
`nl-native-case16594-representation-paired-v1-dev-001`.

This finding is also a design constraint: a future bounded-word checker must
prove ranges for its actual lowered operations or report overflow and fall
back.  Merely replacing the numeric type with `int128` is unsound.

## Derivative work held against hardware arithmetic

A second balanced run holds the padded-double backend fixed and changes only
the generic dense analytic propagation to the existing support-aware compact
jet representation.

| Lane | Mean preparation | Mean 875-cell evaluation | Total recurring batch | Accepted |
|---|---:|---:|---:|---:|
| Dense | 0.047439 s | **0.799856 s** | 0.847295 s | 875/875 |

The compact lane removes 18.10% of directed quotients and 20.27% of interval
products, and its final bounds are very slightly tighter.  It is nevertheless
**2.09% slower** in the balanced five-run mean.  Masking, conversion, and
branch overhead consume the saved arithmetic.  This rejects the current
support-mask representation as the route to the larger gain; it does not
reject specialized derivative algorithms or a truly lowered flat graph.

A one-shot fused-polynomial probe was about 10% faster but accepted only
858/875 cells because its bounds widened materially.  It is rejected under
the complete-certificate gate.  Simple-polynomial preparation plus existing
zero/symmetric operations retained 875/875 but improved only about 1.13x in an
unbalanced probe, so it remains hygiene rather than a new proof target.

## Consequence for the larger programme

The two controlled axes now say different things:

1. On this independent full certificate, arithmetic representation is a
   first-order cost: exact big-integer fixed arithmetic is 23.3x slower than
   the padded hardware discriminator on the identical graph.
2. Reducing generic derivative operation counts by roughly one fifth is not
   enough when implemented with the present compact masks.
3. Even native exact fixed execution is 12.1x faster than the current proved
   reflected fixed-nonlinear computation.  Thus evaluator/data representation
   remains a separate material problem after arithmetic is held exact.
4. The old 340x case-10173 starting gap still explains why algorithmic
   specialization had to be investigated, but it is not a universal residual
   constant.  Case 10173 has already been brought near its historical
   specialized native baseline; case 16594 exposes a different, very large
   arithmetic/evaluator opportunity.

The bounded exact-angle representation proof remains at `d70c17ea`; no new
case-specific soundness development is started from the modest local
specializations above.

The next proof investment is gated by two reusable prototypes:

1. **Proof-safe evaluator lane.**  Encode the accepted fixed-nonlinear checker
   as one flat compact batch whose state contains only fixed endpoints,
   validated certificate cursors, and the live jet data, returning a compact
   verdict.  Compare it against the 875 exact `mpz` outputs.  This targets the
   measured 12.1x reflected/native-exact gap without changing arithmetic.
2. **Bounded-word arithmetic lane.**  Audit which word/integer primitives the
   verified evaluator can execute efficiently.  Prototype checked scaled
   operations with an explicit overflow result and an exact fallback.  Range
   proofs must cover scale-squared Taylor completion and every intermediate;
   the failed `int128` preflight is a mandatory adversarial regression.  Only
   a complete accepted batch with proved outward containment can earn the
   general arithmetic soundness theorem.
3. **Algorithm lane.**  With padded hardware arithmetic fixed, lower one
   repeated case-16594 analytic block into a straight-line centered-jet
   instruction that removes generic stack, mask, and repeated-completion work.
   Run all 875 cells and reject it if acceptance or bound quality regresses.
   This is the meaningful successor to the failed compact-mask experiment.

Preparation, theorem handoff, fallback frequency, peak memory, and complete
batch acceptance remain charged in every gate.  The goal is an amortized
complete-certificate win, not a faster isolated scalar operation.
