## Proof-producing exact-rational milestone

Candle commit `9c005d2` on isolated branch
`codex/cv-exact-rational-v1` adds the first nonlinear-oriented exact arithmetic
substrate behind the repaired verified compute primitive.

The logical representation is `((num#num)#num)`: a signed numerator is stored
as an unreduced positive/negative pair and the denominator is stored as its
predecessor. The represented denominator is therefore always `SUC d`; zero
denominators are unrepresentable. The ordinary layer defines and proves the
real semantics of:

- exact rational addition, multiplication, and negation;
- interval addition and negation; and
- real-containment soundness for those interval operations.

The cval layer provides encoders, decoders, round-trip theorems, evaluator
programs, and representation-correctness theorems. The public adapters execute
the cval programs with `Kernel.compute`, decode the result through proved
round trips, and return ordinary HOL equalities with no assumptions. The tested
ordinary outputs include:

```text
candle_q_add ((3,1),4) ((2,5),2) = ((19,28),14)
candle_q_mul ((3,1),4) ((2,5),2) = ((11,17),14)
candle_q_neg ((3,1),4) = ((1,3),4)
```

Here the first inputs denote `2/5` and `-1`; the addition result is the
unreduced exact `-9/15`. No native floating result, OCaml arithmetic result, or
external oracle is trusted to authorize these theorems.

## Finding that narrows the next target

Review of the actual nonlinear checker confirms that its performance path does
not use arbitrary reduced rationals. Formal bounds are represented as
`float_num sign mantissa exponent`, with base-100 `num_exp` arithmetic and
directed rounding. The exact-rational layer is useful for representation,
kernel theorem handoff, cross-multiplication, and interval soundness, but it is
not by itself the final checker representation. Allowing unreduced rational
numerators and denominators to grow through a full Taylor computation would be
the wrong generalization.

The bounded next steps are therefore:

1. add proved rational ordering/min-max and interval multiplication to complete
   the small exact-arithmetic machinery;
2. bridge promptly to the checker's native `float_num`/`num_exp` representation
   and directed-rounding obligations rather than building a general rational
   normalization library;
3. let replay v17 establish the ordinary first-leaf theorem, then run the exact
   granular profiler to identify the first substantial float/Taylor boundary;
4. preserve the existing theorem conclusions, hypotheses, and axiom set at the
   integration point; and
5. run the full inclusive LP comparison only when another large checkpoint
   restore is memory-safe.

This is a coherent proof-producing prototype milestone, not yet a Flyspeck
release path or an S2/S3 claim.
