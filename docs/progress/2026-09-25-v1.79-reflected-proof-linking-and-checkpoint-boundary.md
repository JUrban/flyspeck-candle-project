## One computed finish replaces repeated subcomputations

The previous prover computed the domain conjunction, Taylor upper bound, box
validity, and final checker result separately. That repeated evaluator work
and then rebuilt the same reduction by rewriting a large term.

The prover now evaluates the established
`candle_cv_q_dim_analytic_first_center_finish` function once over the already
computed center and box results. It then links those assumption-free computed
theorems to the abstract checker call with kernel congruence rules. Program and
box representation are likewise transported with `AP_TERM`, `MK_COMB`, and
`TRANS`, rather than traversing the complete result with general rewriting.

This changes proof construction only. The reflected evaluator, checker
definition, universal correctness theorem, source correspondence, certificate
tree, and final theorem interface are unchanged.
