## Architecture consequence

A verified general OCaml dynamic evaluator is not justified by the selected
proof-script lookup population: those 23,810 occurrences already use the
typed explicit-fallback helper.  The smaller candidate is a hash-bound,
mechanically normalized source overlay that keeps unused reflective bindings
fail-closed and replaces only the selected update-database dependency.

That candidate is not accepted yet.  Static non-use cannot rule out reflective
or externally constructed calls, and `update_database ()` has an actual
load-time side effect.  Before normalization, the reference route must record
whether the resulting theorem database or the definition-only helpers are
observed after initialization.  The normalized route must then match the
reference theorem fingerprints and fail if an unsupported helper is called.
