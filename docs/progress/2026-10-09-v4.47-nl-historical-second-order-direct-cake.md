# v4.47: complete historical dihedral jet through direct `cake`

Date: 2026-10-09 UTC

Status: DEVELOPMENT / NON-RELEASE evidence.  This closes the matched
historical value/gradient/Hessian operation for the captured 4,173 genuine

## Outcome

The existing executable compiler is the inexpensive prototype path.  The
translated checker was compiled directly by
`/project/repos/candle/candle/build/cake`, linked with the system compiler,
and run over all 4,173 captured historical cells.  Every exact value, all six
gradient intervals, and all 21 upper-triangular Hessian intervals matched.

The direct construction costs were:

| Stage | Wall | Peak RSS |
|---|---:|---:|
| Existing `cake` compiles checker S-expression | 4.38 s | 1,080,576 KiB |
| System linker | 0.31 s | 32,256 KiB |

No compiler bootstrap was used.  Changing a verified HOL definition still
requires the reusable HOL-to-CakeML translation/export step; once an
S-expression exists, however, executable experiments take seconds.  A thin
incremental diagnostic translation exposed fixed-list preconditions that
remain a robustness obligation before release use.

## Checked operation and input contract

Each packed cell contains 45 scale-2^40 intervals:

- six box coordinates;
- checked roots for `delta` and `4*x0`;
- nine checked reciprocal certificates;
- the expected box value;
- six expected gradient entries; and
- 21 expected upper-triangular Hessian entries.

The checker recomputes the sign-directed, block-rounded `delta` and
`delta_x4` value/gradient/Hessian data, both optimized triangle-U bounds, the
second-order square root, `b`, the logarithmic U gradient, the historical
dihedral gradient and Hessian, and the fixed-point arctangent value.  Roots,
reciprocals, and expected results are untrusted data: roots and reciprocals
must pass exact word-level certificates, and all returned jet entries must
match the recomputed result.

The first exact-cell run failed closed at the `1/b` certificate.  A staged
observer and an independent exact-integer reconstruction showed that the
arithmetic was correct and the packer had mistaken native execution order for
logical-role order.  Native reciprocal ordinals 11, 12, and 13 are `U126`,
`U135`, and `b`; the checked function consumes `b`, `U126`, and `U135`.
Making the permutation explicit repaired the derived payload without changing
the authenticated native traces or checker arithmetic.
