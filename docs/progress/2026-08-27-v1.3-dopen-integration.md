## Verified Dopen proof build

```text
HOLDIR=/project/worktrees/HOL-cakeml-dopen-v13 \
  /project/worktrees/HOL-cakeml-dopen-v13/bin/Holmake -j1 \
  dopenTestsTheory.uo
```

The isolated build completed 39/39 theories with exit status 0 in 39m30s.
Peak resident memory was 3,904,116 KiB.  The successful stack includes:

- declaration-open evaluation semantics and missing-module failure;
- environment and inference selection through values, constructors, types,
  and nested modules;
- inference-environment well-formedness and type-identifier preservation;
- CV translations for `nsOpen`, `open_ienv`, and `infer_open`; and
- parser-to-inference regressions for accepted constructors, rejected wrong
  arity, nested/repeated opens, preserved qualified lookup, and source-located
  missing-module errors.

The CV translator emitted its normal provisional precondition warnings while
constructing translations; the later proof discharged the relevant
preconditions and the final theory exported successfully.
