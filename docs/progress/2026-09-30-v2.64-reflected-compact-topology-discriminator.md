## What moved into computation

The existing bounded architecture already computes all Taylor numerical
acceptances in `Kernel.compute`, but then decodes each four-cell job batch and
uses `REWRITE_CONV` over native HOL lists, pairs, exact rationals, and split
relations to update the active-root invariant.

The prototype leaves the accepted job list encoded as ordinary `cval` data.
It also encodes the box-free tokens and active-root stack as `cval`. A small
total transition function checks:

- canonical leaf and glue tags;
- job, stack, and list shapes;
- six-dimensional boxes;
- glue-axis bounds;
- exact child-to-parent splits; and
- complete stream consumption.

The recursive evaluator retains only raw job tails and the current encoded
root stack. It uses the existing generic computed exact-split equation rather
than adding a second numerical or geometric definition.

## Proof status and decision

The computed equality theorem for this concrete `cval` call is kernel proved,
but the prototype does **not yet earn nonlinear proof credit**. It still needs
a reusable theorem connecting the encoded transition and stream result to the
existing logical compact runner and its already proved analytic soundness
theorem. The exact root comparison is strong behavioral validation, not a
substitute for that bridge.

The size of the measured recurring win changes the next development priority.
Preserve the active complete theorem attempt, but develop the universal
representation/run-correspondence theorem in the isolated reflected support
lane. If that bridge succeeds, the final adapter can use one computed topology
verdict and one soundness instantiation per bounded segment, avoiding both the
30--35-second native rewrite and the per-token theorem-composition regression
measured in v2.63.
