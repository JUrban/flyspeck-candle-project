## Once-proved exact split composition

Candle commits `d83f6dd` and `16098b4` on
`codex/cv-nonlinear-analytic-v1` add a generic proof-producing binary split
theory. Each internal node records an exact coordinate and exact real split
value. Its soundness theorem derives a root predicate from leaf predicates and
one client closure theorem. A separate well-formedness predicate rejects zero
or out-of-dimension coordinates. The encoded tree and its host producer have no
proof authority.

Flyspeck commit `b8bf63d3` on
`codex/flyspeck-cv-nonlinear-analytic-v1` specializes that result to the actual
`M_verifier.m_cell_pass` and `M_CELL_PASS_GLUE_LEMMA` contract. The left and
right operations are the exact vector-domain cuts used by the checker. The
proof preserves the existing root `m_cell_pass` conclusion and requires both
child pass theorems.

The specialization initially exposed a useful type-safety issue: reparsing an
apparently identical `real^N` witness can invent a fresh finite-index type in
Candle. The committed proof instead extracts the split index and both exact
intermediate endpoints from the already-proved child-domain assumptions. It
therefore preserves their actual type identity and cannot turn an alias or a
reparsed lookalike into proof input.

well-formedness, and returns an assumption-free root theorem. It passed with

`8569af4639c9c7f254c9f5f2840b3bc5039d3449de49157bfb263b502065e50e`.

This fixture uses the exact logical glue statement with a minimal predicate.
The separate real-`M_verifier` source-closure check is active and has not yet
