## Next gates and resources

An independent review must still approve the source choice and exact deltas.
Then two fresh, nonce-distinct 65-target reference sweeps must complete and
agree before an approval can be assembled. The sweeps will run with resumable
artifact-level orchestration but every target remains a fresh HOL process.

The user-authorized 120 GiB value is treated as a heavy-stage ceiling. During
this repair the canonical bootstrap and PFT oracle together used about 40 GiB
RSS and the host retained about 169 GiB available; the GCD oracle used less
than 0.4 GiB. Heavy targets will receive more memory only after live headroom
checks, and the two sweeps need not overlap memory-intensive targets.
