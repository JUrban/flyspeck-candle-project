## Exact authenticated boundary

Every authenticated case-10173 packet must now satisfy the exact source
coordinate-root predicate.  For each center and box coordinate, this checks:

- positivity of the source input and the supplied lower root;
- ordering of the source input interval;
- ordering of the supplied root interval; and
- the exact lower- and upper-square enclosure inequalities.

The checks operate on the original rational `cv` values before rounded
decimal conversion.  The translated packet checker therefore rejects a
rounded root that is numerically useful but is not an exact certificate for
the authenticated source rational.
