The individual opcode bridges now compose through the actual recursive

runner on the canonical encoded instruction list also succeeds and returns
a runtime stack related to the semantic result.

## Proved packet

Candle commit `b64a9ec6c` on `codex/nl-object-dispatch-eval-v1` adds
`bounded_case16594_object_poly_run_eval_runtime_refines`.

The proof is by induction over an arbitrary semantic polynomial program.  At
each instruction it:

1. invokes the generic six-opcode step invariant;
2. threads the resulting runtime stack into the recursive production runner;
3. uses the induction hypothesis for the remaining semantic program; and
4. proves that the real CakeML argument-evaluation sequence produces the
   same recursive call and final related stack.

This checks production evaluator sequencing, stack handoff and the required
clock decrease.  It is not a theorem about a simplified model of the loop.
