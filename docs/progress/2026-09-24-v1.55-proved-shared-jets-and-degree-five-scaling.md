## Correct whole-box contract

The first shared-jet wrapper incorrectly supplied a center-point Hessian to
the Taylor accumulator. That is not a sound whole-box remainder contract: the
Taylor value and gradient are evaluated at the center, but the Hessian must
enclose every point in the box.

Candle commit `7b03915` corrects this before using the wrapper for a proof
claim. It evaluates the compiled expression twice:

1. at the midpoint environment, supplying the center value and gradient; and
2. over the full interval box, supplying the Hessian enclosure.

Each resulting jet is retained as one call-by-value object, so projecting its
components does not repeat either program traversal. The theorem
`candle_cv_q_dim_poly_jet_whole_box_upper_sound_data` now supplies both jets,
the computed Taylor upper equality, center semantic containment, and
full-box semantic containment for every represented environment in the box.

## Plan impact

At this scale, source/program preparation, box conversion, rational growth,
and final theorem handoff are not bottlenecks. The two program traversals
account for essentially the entire recurring cost, and scale roughly with the
instruction count. Prime denominators modestly increase evaluation time, but
the 232/217-bit final rational remains small and does not make theorem handoff
material.

The next performance investigation should therefore target the shared jet
evaluator itself: instruction dispatch, repeated vector/matrix traversal, and
interval normalization inside the center and box runs. The current two-run
analytic contract must be preserved; replacing the full-box Hessian with a
center Hessian would be fast but unsound.

The final reusable proof step remains connecting the proved center/full-box
jet data theorem to the existing multivariate Taylor soundness theorem and an
acceptance theorem for the computed upper bound. In parallel, the genuine
captured leaf and legacy comparison remain the integration tests once the
authenticated nonlinear predecessor emits its readiness marker.
