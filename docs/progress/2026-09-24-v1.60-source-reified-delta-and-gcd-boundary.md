## The 128-step rational-normalization limit is now measured

The same session instruments the final rational representation independently
of the trusted result.  The degree-six, 917-monomial asymmetric-prime case
needs **136 Euclidean steps**.  Because the current proved normalizer permits
128 steps, its safe fallback retains a **3,451-bit nontrivial common factor**;
the final numerator and denominator are 3,720 and 3,703 bits.  The diagnostic
therefore reports `upper_gcd_exceeds_fuel=true`.

This converts the normalization explanation in v1.59 from an inference into a
measurement.  Soundness was never at risk: an exhausted search returns the
unreduced, sign-normalized rational, and every proposed reduction is checked.
The effect is performance and representation growth.  It explains why the
prime-denominator case becomes much more expensive despite the same program
and modest memory use.

The next bounded optimization target is therefore rational normalization, not
the source reifier or theorem handoff.  Suitable proof-preserving candidates
are an adaptive/larger verified Euclidean pass or a checked externally
supplied common-divisor candidate.  That change should be evaluated on the
measured degree-six prime case and genuine captured Flyspeck boxes before any
broader architecture change.
