## Reusable probe implementation

The v671-specific restart logic has been factored into one parameterized,
fail-closed controller.  Stage-specific wrappers supply only the immutable base
directory, fresh output directory, and exact marker.  This preserves the
lessons from `LR-024` and `LR-025`: the default cap includes measured large-heap
restore latency, and interactive markers are counted as exact substrings rather
than incorrectly requiring an unprefixed whole line.

The central long-run hazard check now requires both the v671 and v672
finalization audits, and checkpoint-integrity checking includes both receipts.
No remaining-support probe or theorem attempt is authorized merely by the
existence of these checkpoints; each still requires its own exact preflight and
bounded question.
