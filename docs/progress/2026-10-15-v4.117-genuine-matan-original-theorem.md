## What this does and does not establish

This closes the architecture for one real inequality: genuine source and box
to a compact computed verdict to the original theorem, without replaying the
roughly 200-second generic exact Taylor reconstruction.

It does **not** yet establish that all nonlinear Flyspeck targets can be run by
this checker or that total throughput is sufficient.  A naive extrapolation
from a cold single-case run would be misleading because it charges checkpoint
restore, reusable source preparation, proof loading, and theorem printing to
every case.  Conversely, the historical 23,000-plus inequality count makes it
unsafe to assume that one accepting root predicts total cost.
