## Pure implementation and boundary

`candle/ocaml.ml` implements `regexp`, `split`, `string_match`,
`global_replace`, and `first_chars`.  The regular-expression subset covers all
literal forms in the selected graph: literals, dot, character classes with
negation/ranges, `*`, `+`, `?`, and start/end anchors.  Splitting preserves
interior empty fields and trims edge empties like OCaml 4.14.1.

Unsupported escaped grouping, alternation, back-references, replacement
back-references, and empty-match global replacement fail explicitly.  One
loaded definition constructs `".*" ^ s` from an argument, so arbitrary dynamic
regex behavior is not claimed.  The manifest therefore labels `str.cma`
`partial-pure-source-differential-gate`; `unix.cma` remains `unimplemented`,
and the overall contract remains
`blocked-pending-static-binding-evidence`.
