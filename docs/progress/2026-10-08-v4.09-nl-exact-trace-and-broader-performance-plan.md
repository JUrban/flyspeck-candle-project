## Concrete orders-of-magnitude plan

The next performance packet is the complete checked-word executor already
motivated by the mixed-width factorial, not another expression-specific proof:

1. retain narrow stored endpoints and checked two-limb operations, using a
   checked three-limb accumulator only for Hessian weighting and Taylor
   recomposition;
2. return overflow as data and refine every successful word result to the
   current exact natural-number operation, with the unchanged exact evaluator
   as fallback;
3. run one closed 875-cell program that returns only count, digest, fallback
   count, bounds, and verdict;
4. charge source/input preparation, conversion, numerical execution,
   fallback, verdict/theorem handoff, required repeats, total elapsed time,
   and peak memory separately;
5. require 875/875 acceptance and a first fully charged gate below 22.58
   seconds, then repeat on the independent 4,173-cell family; and
6. profile the accepted executor before choosing the next architecture:
   fixed-layout execution if dispatch/traversal dominates, a lower-work
   root/inverse/arctangent kernel if unary work dominates, or a compact
   one-verdict bridge if theorem handoff/repeated evaluation dominates.

The current negation/addition completion proof is retained because it is
general and is required for exact native parity.  No broader fused-expression
or per-expression calculus proof is authorized by the present measurements.
Any larger specialization must first produce a material complete-batch win on
both real families with unchanged acceptance and sound outward bounds.
