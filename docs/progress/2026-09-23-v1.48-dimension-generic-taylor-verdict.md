## Intended universal analytic theorem

The destination remains one constructor-level result for every valid
expression in the supported language.  Schematically, after the remaining
vector/Flyspeck bridge is proved once, the target has the form:

```text
valid N e /\
box_shape N box /\ box_valid box /\
domain_ok e box /\
computed_accept e box
==>
!x. x IN box ==> denote e x < 0
```

The reusable proof must establish for arbitrary valid `e` that the reflected
jet components denote the actual Flyspeck `partial` and `partial2`
derivatives, satisfy the smoothness/domain hypotheses of Flyspeck's Taylor
theorem, and enclose all required values over the box.  That connection is
general over the expression syntax, not a new calculus proof per expression.

Per real Flyspeck expression, the intended remaining obligations are only:

1. an authenticated mechanical reification/source-equality theorem;
2. syntactic validity and operator-domain certificates;
3. exact box/certificate data; and
4. computed acceptance.

Adding a new primitive operator family may require one reusable analytic and
interval proof for that constructor.  Merely adding another expression built
from supported constructors must not require handwritten derivative or
remainder proofs.
