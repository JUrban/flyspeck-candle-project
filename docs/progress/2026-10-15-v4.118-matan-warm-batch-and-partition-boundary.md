## Consequence for the all-NL route

The universal analytic theorem and original-source handoff are working, but
replaying 1,335 cells through separate 50-second generic evaluations would be
the wrong production architecture. The next bounded milestone is therefore:

1. capture or deterministically recreate the exact untrusted leaf-box forest
   for these four components;
2. encode a complete fail-closed batch in which each leaf checks both source
   alternatives and records the accepting branch;
3. run the batch through the directly compiled CakeML checker, with complete
   guards and certificates;
4. connect one successful batch verdict to compact reflected terminal and glue
   soundness theorems, producing all four original `ineqm` component theorems;
5. use `Break_case_exec.prove_iargs_cases` to recover the original
   `prep-5202826650 a` theorem; and
6. report reusable preparation, recurring execution, theorem handoff, total
   elapsed time and peak memory separately.

The generic `Kernel.compute` route remains a trusted oracle and proof
development tool. The directly compiled, proof-connected checker must be the
recurring engine for certificate forests of this size. This keeps the next
debug cycle at checkpoint/capture scale rather than an 8--10-hour replay.
