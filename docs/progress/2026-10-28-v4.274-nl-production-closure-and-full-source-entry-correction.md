## Important boundary correction

That theorem is **not yet a closed HOL Light theorem for a cell**, and it
cannot yet be fed directly into the existing 875-cell topology adapter.

The five-argument entry `candle_cv_q_packed_object_accept6` checks only the
final exact Taylor arithmetic over supplied radii, center value, center
gradient, and packed Hessian.  Its HOL Light correctness theorem derives the
negative final bound, but the analytic cell theorem still separately requires
proofs that those supplied values enclose the original expression, its first
derivatives, and its second derivatives on the box.

The HOL4 hypothesis `bounded_packed_analytic_object_cell` contains exactly
that source-evaluation fact.  However, a HOL4 hypothesis is not automatically
a HOL Light theorem, and the current five payloads do not contain the source
program, box, or certificates from which a generic runtime checker could
re-establish it.  Therefore:

```text
accepted packed source cell
  -> exists final payloads whose Taylor suffix accepts
```

is proved, while the production bridge still needs:

```text
accepted packed source cell
  -> ordinary Candle full source-evaluation entry accepts
  -> HOL Light analytic cell theorem
```

Calling the first arrow the complete trusted cell handoff would be wrong.
Likewise, composing the final arithmetic suffix with the 875-cell topology
would leave the source-containment premises unproved.

## Revised bounded route to the first fast original theorem

1. **Freeze the full-entry contract on paper and in theorem statements.**
   The ordinary entry must consume enough authenticated source, box, and
   certificate data for its HOL Light correctness theorem to imply the
   analytic containment premises.  A final-arithmetic-only entry is not
   sufficient.
2. **Reuse the existing full exact evaluator if possible.**  The preferred
   target is a Boolean acceptance wrapper around the already proved fixed
   nonlinear certified checker, so a fast callback need return only the
   acceptance bit rather than reproduce the exact rational upper endpoint.
   If its input representation cannot express the separated packed source
   and certificates, add one small ordinary wrapper that decodes them and
   invokes the same exact evaluator; do not introduce a family-specific
   theorem table.
3. **Prove the HOL4 refinement for that full entry.**  Generic packed
   acceptance must imply default-clock `compute_eval` success for the full
   ordinary call.  The proof must be source- and cell-parametric and retain
   equation-set and entry identity checks.
4. **Close one genuine HOL Light cell.**  Use the resulting equality with the
   existing analytic theorem, checking zero assumptions and zero axiom
   growth.  This is the next result allowed to be called the first fast cell
   theorem.
5. **Only then fold 875 cells and topology.**  Reuse the existing 1,749-token
   case-16594 topology and literal theorem adapter, and require the established
   theorem digest `8bb2c1bf3d1c1944d497c0da68b88207`.
6. **Repeat the semantic entry on a second family before a runtime rebuild.**
   This preserves the generic-runtime gate from plan v2.
