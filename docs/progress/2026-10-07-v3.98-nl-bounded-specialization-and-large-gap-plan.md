## Bounded specialization proof is complete

CakeML commit `99603c8aa` closes the deliberately small proof packet for the
six imported delta roles.  The new theory:

- evaluates the exact imported postfix programs over arbitrary integer
  six-coordinate inputs;
- proves the three 85-instruction programs equal `4*x_i*delta`;
- proves the three 39-instruction programs equal their stated negative delta
  derivative formulas; and
- proves exact symmetric-difference characterizations for those derivative
  formulas, exploiting that delta is quadratic in each relevant coordinate.

The proof does not authorize position-, length-, or basename-like aliases.
Dispatch still requires the exact previously authenticated program identity.
The focused HOL4 build passed in 17.80 seconds with 345,176 KiB peak RSS.

This is the stopping boundary for the local proof.  Lifting these polynomial
identities into the general analytic/rational source theorem remains a
release obligation, but no further case-specific calculus layer is started.

## Concrete larger-gap plan

The current integration gate remains one compact, total, fixed-width checker
over the complete 875-cell batch:

1. keep stored signed interval endpoints at the measured 64-bit boundary,
   use proved 128-bit raw products/dot accumulators and 192-bit weighted and
   Taylor accumulators, and return overflow explicitly to the unchanged exact
   fallback;
2. execute the complete authenticated 167-instruction program, dispatching
   only the six exact delta identities proved above;
3. keep all intermediate jets as data and return only the compact bounds,
   digest, and verdict required by the universal analytic theorem;
4. charge input/program preparation, conversion, numerical evaluation,
   fallback frequency, theorem handoff, required repeats, and peak memory;
5. require 875/875 certificate acceptance and exact expected bounds, with
   **22.58 seconds** as the first tenfold integration gate against the
   225.8-second reflected control; and
6. validate the resulting architecture on the genuine case10173 family
   before general proof expansion.

Only after the complete-batch profile exists will another native algorithm
experiment be promoted.  The cheap controlled candidate is to hold the
winning word backend and complete-box Taylor contract fixed while replacing
one measured dominant elementary block (coordinate root or
inverse/root/atan-dihedral propagation) with a reusable source-authenticated
instruction.  It must preserve the entire certificate's acceptance and
enclosure quality, not merely accelerate a leaf.  This keeps the historical
specialized-algorithm lesson active without letting an unmeasured local proof
delay the much larger verified-execution opportunity.
