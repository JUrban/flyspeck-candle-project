## Evidence split

Coverage-v1 remains the exact compiled-runtime artifact.  It retains action
`load`/`skip-ledger` outcomes, loader request nesting, cache state, Candle
control keys, selected normalization execution records, raw certificate event
order, and nonce-free event digests.  It is required in compiled descriptors
and is never accepted in pristine-reference descriptors.

Coverage-v2 contains only common facts independently reproducible from the
shared authenticated plan and each runtime's retained native observations:

- final boundary and 297 ordered action identities with successful completion;
- the exact 400-node original-source inventory;
- explicitly labelled Candle plan execution selections, without claiming that
  pristine OCaml executed the normalization overlay;
- every action root plus authenticated selected nested logical sources;
- all 43 generated inputs;
- structural, LP, nonlinear, final-premise, and final-implication completion;
- 39 canonical certificate identities, each with one successful
  deserialization; and
- categorical `pft_used = false`.

It omits Candle physical events, cache outcomes, controls, raw LP order, and
per-event identifiers/digests.

## Exact alias and closure repair

The first hostile review found that a generic safe-relative validator rejected
46 real plan targets with one leading `..`, and that the synthetic fixture did
not require action roots in the selected closure.  The repaired resolver treats
targets as lexical paths relative to `text_formalization`, permits at most one
leading parent, rejects every escape or embedded parent, and requires the
resolved identity to equal the authenticated `flyspeck:` selected source.

The resolver passes all 297 current plan actions: 39 `formal_lp`, six
`jHOLLight`, one `formal_graph`, and 251 ordinary text-root targets.  The
coverage validator now requires every action selected source to occur in the
common logical closure.  The compiled adapter constructs the closure as the
union of validated completed action roots and the non-control/non-derivation
nested records already authenticated by coverage-v1.

## Role-correct authority

Authenticated schema-6 capture-v2 rederives and binds both coverage-v1 and
coverage-v2 from the same retained receipt and plan.

Comparison descriptor-v2 has exact disjoint roles:

- compiled: semantic projection, common coverage-v2, detailed coverage-v1;
- pristine reference: semantic projection, common coverage-v2, and a distinct
  authenticated native execution-closure content record.

Comparison-v2 requires exact three-way semantic and coverage-v2 equality, one
shared plan, three distinct candidates/nonces, two distinct reference closure
records, exact producer/validator authorities, and the status
`three-way-semantic-and-cross-runtime-coverage-match-unapproved`.  Detailed
coverage-v1 is bound only to the compiled descriptor.  Every promotion,
approval, S2/S3, release, and PFT field remains false.

Inline compiled descriptor production still occurs only after final raw
receipt/log/snapshot/tree/link/plan/repository/source revalidation, named
directory checks, and the last held-lock check.  There is no detached
descriptor assembler or public minting helper.

## Next boundary

The opaque reference execution-closure record is not self-authenticating.  A
new pristine-reference producer/validator must define its exact raw schema,
authenticate original-source execution with serialization disabled, retain raw
native loader and LP order, independently derive semantic and coverage-v2, and

descriptors.
