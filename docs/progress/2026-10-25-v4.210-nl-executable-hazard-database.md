## Owner process correction

The durable hazard database is
`docs/long-run-hazard-ledger.json`.  It now records 29 observed or anticipated
failure classes.  A hazard has a scope, classification, first evidence,
failure mode, root cause, executable check, and enforcement phase.  An unknown
active check fails closed.  A failed expensive run may not be retried until
its new failure class and cheap discriminator have been recorded.

The threshold is now 1,800 seconds rather than one hour.  Consequently the
3,300-second segmented support stages are integration runs and must produce a
green central preflight receipt over the exact ledger and controller bytes.
The gate has separate theorem and support-stage profiles so a checkpoint stage
does not silently inherit an obsolete experiment or omit a stage-specific
contract.
