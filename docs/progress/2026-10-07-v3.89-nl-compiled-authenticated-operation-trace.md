## Broader performance investigation

The two original observations remain deliberately separate:

1. encoded proof-producing execution versus exact native execution; and
2. generic derivative/Taylor work versus the historical specialized C++
   algorithm.

The historical roughly 340-times case10173 result is a starting-architecture
diagnosis, not its current residual.  Controlled native changes have reduced
that fixture's numerical residual to about 1.35 times.  On the independent
case16594 family, holding exact mixed arithmetic fixed while introducing the
two authenticated delta instructions improved recurring native evaluation
1.839 times, and holding that analytic graph fixed while changing interval
product selection added another 1.104 times.  Conversely, holding the graph
fixed while changing exact versus padded hardware arithmetic still differs by
roughly 2.2 times after sign classification.  The experiment therefore
separates algorithm, arithmetic representation, and formal execution rather
than assigning the whole gap to one of them.

The current largest measured boundary is now the roughly 198-times gap between
the 225.8-second reflected batch and the 1.138-second exact native accepted
candidate.  The 6.34-second trace indicates that a compact proved executor can
remove much of it, but only the actual 875-cell theorem-producing run can make
that claim.
