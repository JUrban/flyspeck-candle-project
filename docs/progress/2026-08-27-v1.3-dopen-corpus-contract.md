# v1.3 Dopen corpus contract — 2026-08-27

The direct manifest now carries an exact declaration-open contract for the
reachable 400-node source graph.  It records:

- 3,180 declaration-open occurrences;
- 234 affected Flyspeck files;
- 193 distinct module paths;
- 3,180 simple paths, no dotted paths, and no `open!` sites; and
- canonical site SHA-256
  `bce30814051df12ea23c14f2918a55e6b839b72760fd58b8996e32f1c05bf282`.

The site digest covers the selected source identity, line, normalized module
path, path form, and warning-suppression flag.  Local `let open` and
parenthesized local-open expressions are separate frontend forms and are not
counted as Dopen declarations.

This is an inventory and G2 acceptance contract, not verified Dopen closure or
an S milestone.

## Independent cross-check and reproducer

The project compatibility scanner, independently filtered by exact selected
source path and SHA-256, reports the same 3,180 declaration records.  Every
selected Flyspeck file containing a declaration open has the same hash in the
inventory and direct manifest.  The one selected hash mismatch in the broader
open-family comparison is `candle/ocaml.ml`; its six sites are parenthesized
local opens and do not belong to Dopen.
`scripts/check-direct-dopen-corpus.py` makes this comparison an executable lock
gate and recomputes the canonical digest from the independent findings.

`compatibility/oracles/open_declaration.ml` passes on pinned OCaml 4.14.1 and
the current compiled Candle reports `open-declarations are not supported
(yet)`.  The clean direct-loader log exhibits that same failure at
`general/debug.hl:16` after `parser_verbose.hl` completes.

## G2 consequence

G2 requires the verified inference stack and compiler to build, the minimal
OCaml differential to pass in the rebuilt executable, and a real
corpus-derived open-dependent slice to match reference fingerprints.  The
first direct slice is the existing authenticated `parser_verbose.hl` followed
by `debug.hl`; after Dopen integration, `debug.hl` must complete and expose its
expected `Debug` bindings before the loader advances.  The subsequent prefix
gates must use the recorded stratum distribution.  Source rewriting to qualify
thousands of names is not the selected remedy.
