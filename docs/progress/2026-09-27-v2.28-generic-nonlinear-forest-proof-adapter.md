## Result

The proof-producing action-296 path is no longer tied to a handwritten
batch-specific harness.  Candle commit `8c2f7afe` introduces a generic
data-driven adaptive-forest adapter and reduces the stratified 16-root proof
to a compact recursive split plan.

Each configured root is ordinary untrusted data built from only:

- `leaf`; or
- `split axis left_plan right_plan`.

The adapter independently:

1. resolves the exact original precision leaf and source box;
2. authenticates and prepares its source expression;
3. derives every final subbox by kernel-backed Flyspeck split operations;
4. constructs and proves an aggregate reflected check over the selected final
   cells;
5. extracts assumption-free cell-source theorems;
6. transports each theorem to the exact live Flyspeck domain; and
7. glues the recursive tree back to its original root theorem.

It rejects out-of-order or out-of-range roots, invalid axes, unexpected cell
counts, changed source functions or root domains, hypotheses, digest drift,
and global axiom changes.

## Policy materialization

The same commit adds a strict discovery-log validator and ML plan renderer.
It checks:

- unique, contiguous configured indices;
- exact 13-bit parent/child and 12-bit grandchild result shapes;
- direct-parent acceptance;
- selected one-split viability;
- exact rejected-branch sets at depth two;
- selected second-axis viability;
- final-cell counts; and
- explicit preservation of unresolved leaves.

An unresolved leaf cannot be emitted as a proof plan.  The renderer labels its
output as untrusted and the generic adapter still recomputes every final cell.
Three focused unit tests pass, including rejection of a non-viable selected
axis.  Materializing the completed leaf-696 smoke log produced the expected
axis-6 tree with an axis-4 split below its left branch and three final cells.
