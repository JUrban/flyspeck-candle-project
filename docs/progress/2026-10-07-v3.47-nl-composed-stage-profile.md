## Decision

The current addition and dyadic proof targets stay bounded and reusable, but
neither should become a long standalone proof project. The data rejects a
third isolated dihedral attempt: generic whole-chain fusion already lost
certificate coverage, and the faithful historical fixed graph remained
slower even after shift rounding.

The next cheap discriminator is a whole-graph range audit. It will determine
whether normalized fixed endpoints fit signed 64 bits while raw products and
accumulators require signed 128 bits. If so, a split-width native prototype
can hold the authenticated derivative/Taylor graph and all rounding decisions
fixed while changing only representation width. It must preserve every final
bound at the same dyadic scale and accept the full batch. This tests a
distributed cost which the stage profile shows no local primitive can remove.

The 0.063347-second geometry conversion is separately reusable preparation.
Moving it between reported phases does not improve a cold single-expression
batch; reuse is credited only when several checks actually share the same
fixed box geometry. The larger architectural target remains a generally
proved complete-box checker or low-work numerical instruction, assessed on
complete certificate time and enclosure quality rather than isolated kernel
speed.
