## First source-to-analytic shared-jet composition

The reciprocal constructor is now connected to the existing source reifier
and compact polynomial shared-jet evaluator. The focused source
`inv (&2 + x)` is processed as follows:

1. the theorem-producing reifier authenticates the child `&2 + x` and emits
   its three-instruction postfix program;
2. the existing dimension-generic evaluator computes one value/gradient/
   Hessian jet for that child;
3. the reflected reciprocal transformer consumes that jet as data; and
4. a generic theorem derives the reciprocal value, gradient, and Hessian
   enclosure contract.

The new ML reifier returns an assumption-free theorem equating the reciprocal
of the polynomial AST denotation to the original HOL source term. ML chooses
the child AST but supplies no mathematical authority. The ordinary and cval
programs have representation theorems for both the resulting jet and its
computed nonzero-domain decision.

For an exact point box `x = 0`, the test checks the complete exact result:

```text
source       inv (&2 + x)
instructions 3
value        1/2
gradient    -1/4
Hessian      1/4
```

This is the intended shared-jet route: one compact compiled child program,
not separately expanded value and derivative programs. The current adapter
supports a top-level reciprocal of a polynomial child; it is deliberately a
bounded integration step, not yet the full nested analytic AST required by
action 296.
