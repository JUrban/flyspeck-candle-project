## Why the existing exact checker was not wrapped directly

The existing `candle_cv_fsn_variable_raw_jobs_check` already has strong HOL
Light soundness and checks complete source programs.  Static comparison found,
however, that it computes nonlinear intervals by its own exact algorithms,
including rational inverse and arctangent evaluation.  The packed checker
accepts supplied outward-rounded nonlinear certificates and uses authenticated
delta specializations.  Those implementations can produce different, still
sound enclosures.  Thus packed acceptance is not by itself a proof that the
old exact Boolean checker accepts the same cell.

The durable route is to check the packed nonlinear outputs against exact
semantic certificate predicates in ordinary Candle.  HOL Light soundness then
derives analytic source containment, while the HOL4 fast refinement may skip
repeating the slow exact specification after proving the same predicates.
