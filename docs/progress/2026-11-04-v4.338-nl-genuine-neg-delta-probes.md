artifacts currently contain different identities for the foundational
`compute_exec` theory.  A helper definition was moved into that foundational
theory after the semantic cache was built.  Consequently, the two proof
families cannot yet be loaded together from the present mixed cache.

An attempted target build correctly revealed this before any long run.  The
first broad preflight was stopped after 72 seconds when it requested 186
theories.  Later focused rebuilds were kept under five-minute caps, but were
stopped when unrelated cached inverse artifacts regenerated.  This is a
build/integration issue, not a failed NL semantic theorem or failed genuine
negative-delta computation.
