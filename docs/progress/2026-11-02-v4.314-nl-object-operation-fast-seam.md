representation, checked-candidate pattern, literal dispatch, and Candle

object multiplication, that the inverse derivative is cheap, that a genuine
case-16594 cell reaches this branch, or that the original HOL Light theorem is
obtained.  Those are now separate, falsifiable gates rather than assumptions
inside a long run.
