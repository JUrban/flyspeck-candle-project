# V4 validator implementation checkpoint — 2026-08-30

## Boundary

This branch starts from exact authority checkpoint `3a1c54f` and implements
the first positive, pure validators needed by the future isolated native-build
receipt.  It does not yet validate a complete execution observation or native
receipt, run a supervisor, publish a candidate, or claim approval/PFT/S2/S3.

## Implemented leaf validators

`pristine_direct_reference_protocol.py` now validates exact built-in JSON
types and cross-field invariants for:

- OFD flock mode;
- supplementary groups and their ordered digest;
- each bounded capability set and the exact five-set object;
- signal-set raw bits, sorted members and ordered digest;
- signal action flags/mask and alternate-stack state;
- registered/unregistered robust-list and rseq state; and
- the domain/NUL/ordered-value-array state-digest framing helper.

The second slice adds complete credential and task-control containers plus
the plural capability-set transition.  It checks all real/effective/saved/fs
UID/GID values, securebits, five capability sets, NNP/seccomp consistency,
all 64 ordered signal dispositions and their digest, blocked/pending masks,
FS/GS bases, clear-child-tid, robust/rseq state and the no-`STICKY_TIMEOUTS`
personality invariant.  Capability transitions require a canonical nonempty
set-name list that equals the fields whose exact values actually changed; an
operation-specific caller can additionally require the capset triple.

All integer checks reject bool subclasses.  Lists are bounded, ordered and
duplicate-free where the authority requires it.  Signal masks cross-check all
64 raw bits; blocked masks reject SIGKILL and SIGSTOP.  Alternate-stack,
robust-list and rseq registered/unregistered forms are canonical rather than
accepting equivalent loose dictionaries.

## Verification

The protocol suite is 21/21 after adding hostile cases for wrong counts,
duplicates, out-of-range and boolean integers, raw/list disagreement, unknown
signal and stack flags, malformed robust/rseq sizes, extra keys and unknown
lock modes, UID bools, unknown securebits, inconsistent seccomp mode/count,
disposition-digest drift, sticky personality, mislabeled plural capability
changes and boolean transition indexes.  `py_compile` passes.  The last full
focused regression gate before this slice was 58/58; generator/parser gates
will be rerun after the next structural validator slice.

Next implementation slices are the exact credential/task-control containers,
mount-namespace clone map, initial-state seed, setup replay and finally the
complete event/transition validator and descriptor-rooted joins.
