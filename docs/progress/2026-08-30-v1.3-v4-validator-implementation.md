## Implemented leaf validators

`pristine_direct_reference_protocol.py` now validates exact built-in JSON
types and cross-field invariants for:

- OFD flock mode;
- supplementary groups and their ordered digest;
- each bounded capability set and the exact five-set object;
- signal-set raw bits, sorted members and ordered digest;
- signal action flags/mask and alternate-stack state;
- registered/unregistered robust-list and rseq state; and
- the domain/NUL/ordered-value-array state-digest framing helper.

The second slice adds complete credential and task-control containers plus
the plural capability-set update transition.  It checks all real/effective/saved/fs
UID/GID values, securebits, five capability sets, NNP/seccomp consistency,
all 64 ordered signal dispositions and their digest, blocked/pending masks,
FS/GS bases, clear-child-tid, robust/rseq state and the no-`STICKY_TIMEOUTS`
personality invariant.  Capability updates require a canonical nonempty
target-set list, preserve all untargeted sets, derive the exact idempotent flag
from before/after equality, and allow an operation-specific caller to require
the capset triple.  The obsolete pre-authority
`capability-sets-change/changed_sets` spelling is not accepted.

All integer checks reject bool subclasses.  Lists are bounded, ordered and
duplicate-free where the authority requires it.  Signal masks cross-check all
64 raw bits; blocked masks reject SIGKILL and SIGSTOP.  Alternate-stack,
robust-list and rseq registered/unregistered forms are canonical rather than
accepting equivalent loose dictionaries.
