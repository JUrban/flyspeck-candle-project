## Implemented leaf validators

`pristine_direct_reference_protocol.py` now validates exact built-in JSON
types and cross-field invariants for:

- OFD flock mode;
- supplementary groups and their ordered digest;
- each bounded capability set and the exact five-set object;
- signal-set raw bits, sorted members and ordered digest;
- signal action flags/mask and alternate-stack state;
- registered/unregistered robust-list and rseq state; and
- the domain/NUL/ordered-value-array state-digest framing helper.

The second slice adds complete credential and task-control containers plus
the plural capability-set update transition.  It checks all real/effective/saved/fs
UID/GID values, securebits, five capability sets, NNP/seccomp consistency,
all 64 ordered signal dispositions and their digest, blocked/pending masks,
FS/GS bases, clear-child-tid, robust/rseq state and the no-`STICKY_TIMEOUTS`
personality invariant.  Capability updates require a canonical nonempty
target-set list, preserve all untargeted sets, derive the exact idempotent flag
from before/after equality, and allow an operation-specific caller to require
the capset triple.  The obsolete pre-authority
`capability-sets-change/changed_sets` spelling is not accepted.

All integer checks reject bool subclasses.  Lists are bounded, ordered and
duplicate-free where the authority requires it.  Signal masks cross-check all
64 raw bits; blocked masks reject SIGKILL and SIGSTOP.  Alternate-stack,
robust-list and rseq registered/unregistered forms are canonical rather than
accepting equivalent loose dictionaries.

## Descriptor-rooted setup migration

The structural root leaf now consumes the accepted closure-v2/chroot and
execution-observation-v7 authority.  It requires exactly one initial
`setup-root` and one initial `input-root`, exact root selector nullability,
stable descriptor/mount/device/inode generations, and the initial-edge list
digest.  The setup root joins the initial FS root and row-zero mountpoint of
the builder mount graph.  The input root joins the closure root identity and
positive root-fd generation, exactly one live input-root fd and exactly one
OFD; the retained fd/OFD access strings, generation, object-edge index,
reference count and lock state all agree.  The full descriptor-policy literal
remains the responsibility of the future complete initial-state validator.
This is a join validator over already observed identities;
it does not pretend to replace the future complete mountinfo/initial-state
validator.

Setup event edges dispatch in literal `V4_BUILD_SETUP_SEQUENCE` order.  The
four root steps must equal the pure
`enumerate_isolated_native_build_setup_root_edge_v1` result and the remaining
setup steps have their authority-declared zero edge count.  Mount `/`, fchdir,
chroot `.` and chdir `/` entry captures retain exact bytes and arguments;
fchdir selects the joined fd/generation.  Their mount/cwd/root transitions and
before/after FS states are derived in order; the propagation transition covers
every retained builder mount, including the selected setup root, and the final
idempotent chdir still advances the replay generation.  Post-filter dispatch
admits only the three ordinary edge
domains and rejects both setup-only domains before domain-specific decoding.
