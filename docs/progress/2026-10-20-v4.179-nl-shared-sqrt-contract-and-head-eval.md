## Headline

The corrected actual-operand square-root facts now live in one executable
recursive contract, and one step of that contract has been proved sufficient
for registered evaluation of the unchanged literal `fsn_result_sqrt` source
operation.  The proof hands the already checked fast decimal result to the
source evaluator theorem; it does not repeat the generic numerical
calculation.

This closes the local single-coordinate handoff identified by Review 1.  It
does **not** yet prove the six-coordinate source prefix, an arbitrary complete
job, default-clock kernel dispatch, or the literal original Flyspeck theorem.
Fast-route literal original theorems therefore remain **0**.

The first commit adds a canonical recursive contract which, for each actual
Taylor-completed coordinate operand:

1. recomputes the exact completed variable state;
2. converts both center and whole-box values to the rational source form;
3. authenticates both supplied rational square-root roots against those exact
   values;
4. authenticates their fixed-point interval images;
5. authenticates the direct second derivative against the actual whole-box
   operand; and
6. requires the fast decimal square-root operation to succeed on that same
   Taylor state.

Its decomposition theorem exposes these witnesses and the remaining recursive
contract without substituting the original source box.

The second commit proves
`registered_case10173_actual_sqrt_source_prefix_head_eval`.  From one such
contract step, six-dimensional shape, and the current local clock premise, it
derives a registered `compute_eval` success for the unchanged
`candle_cv_fsn_result_sqrt` call and the encoded fast result.  This consumes
the previously proved exact conversion, root/domain, derivative, Hessian, and
source-result bridges.
