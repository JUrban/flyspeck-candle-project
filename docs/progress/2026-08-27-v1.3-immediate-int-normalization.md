## Semantics-preservation argument

The reference implementation is the official OCaml `4.14.1` tag, commit
`99cb5d93fc30f1a6f3e69f5aa5d2063994d33a93`:

1. `stdlib/stdlib.ml:69-77` maps structural `=` to `%equal` and physical `==`
   to `%eq`.
2. `lambda/translprim.ml:165` maps `%eq` directly to `Pintcomp Ceq`.
3. `lambda/translprim.ml:475-482,543-547` recognizes a statically known
   `int` and maps structural equality to the same `Pintcomp Ceq`.
4. Independently, `runtime/caml/mlvalues.h:75-80` encodes every `int` as the
   injective tagged word `((uintnat)x << 1) + 1` and decodes by shifting right.

Both source predicates therefore lower to the same primitive for every
representable `int`; the argument is not an extrapolation from test samples.
Changing the operator leaves the two LP branches and all effects untouched.

Seven host tests cover exact application, input drift, ambiguous anchors,
output drift, deterministic receipts, overwrite refusal, and the narrow
one-entry contract.  A pinned OCaml oracle samples boundary and ordinary ints;
a compiled Candle oracle accepts `=` and exercises both branches.  The full
manifest's 23 tests and its independent complete regeneration also pass.
