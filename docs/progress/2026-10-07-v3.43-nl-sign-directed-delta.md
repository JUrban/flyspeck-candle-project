## First low-work numerical stage

The first stage of the historical low-work dihedral experiment now implements
the `setDeltaFull` monotonicity structure under the same scale-`10^7` fixed
arithmetic as the accepted 4,173-box native lane.  Hessian signs choose endpoint
environments for gradient bounds, and the resulting gradient signs choose
endpoint environments for the value bound.  A mixed sign retains the original
box coordinate.

Twenty warmed measurements over all 4,173 boxes gave:

| Delta enclosure | Mean time | Interval products |
|---|---:|---:|
| Generic interval polynomial | 0.033646651 s | 146,055 |
| Sign-directed `setDeltaFull` | 0.051894936 s | 617,604 |

The candidate costs 1.542 times the generic calculation in isolation.  It is
not a speedup claim.  It tightens all 4,173 value bounds and all 25,038 gradient
bounds, reducing aggregate value width to 14.34% and gradient width to 42.04%
of generic.  Hessian bounds are identical.

The development validation checked all value, gradient, and Hessian entries at
all 64 vertices of each box, totaling 267,072 vertices, and required each
candidate enclosure to be contained in the generic enclosure.  Native and
overflow-checked `int128` runs passed with identical width totals.  This is a
fixture-level implementation check, not a formal soundness result.

## Decision

No standalone `setDeltaFull` proof is started.  The historical route may spend
more work here to obtain tight derivatives and then avoid much larger generic
chain-rule/Taylor costs.  The measured 1.542-times delta cost remains charged
to the eventual complete batch.  The next bounded stage joins this data to the
historical derivative-square-root and `setDeltaX4` calculations; the native
complete-dihedral gate still decides whether any new instruction theorem is
worth proving.
