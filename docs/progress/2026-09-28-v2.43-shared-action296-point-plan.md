## Consequence

This closes the cheapest source-only reuse opportunity identified in the
architecture review. It does not address the dominant repeated box-source and
per-cell variant proof construction.

The next bounded architecture discriminator is one stable authenticated
instruction skeleton plus box/center square-root intervals supplied as
ordinary checked data. It should first retain the current arithmetic and
exact hint values, so 1/8/32-box measurements isolate data-interface savings
from numerical changes. A proof-producing interface is justified only if
that untrusted layout materially reduces recurring preparation while
preserving exact acceptance and cell coverage.

No second complete 1,061-root run is started for this isolated change. The
already active clean replay remains the whole-workload baseline for the
current grouped design.
