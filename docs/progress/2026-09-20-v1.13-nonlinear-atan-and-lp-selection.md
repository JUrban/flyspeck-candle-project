## Proof-producing LP interface preservation

The real terminal harness exposed one deterministic legacy interface rule
that must be preserved before claiming theorem equality. Flyspeck's
`prove_flyspeck_lp_step1` groups target and variable-bound rows by variable.
When a group's cumulative left coefficient becomes zero, it drops the whole
group, including its right-hand side and hypotheses; a later row for the same
variable starts a fresh group.

Commit `52e0c5af9ab7d5c06228b31db6a580b8d9c7bef4` adds an authenticated
proof-input selector that mirrors this behavior before reflected bulk
combination. It standardizes exact numeral weights, rejects negative weights
and non-singleton auxiliary rows, simulates the reset rule, and sorts surviving
groups with HOL Light's term ordering to match the legacy stable order. A
focused cancellation/restart test with two variables passes, including both
fail-closed guards.

The prepared complete `hard_2` harness now applies the selector to bounds and
targets in legacy order and appends the independently handled global row. It
will compare the complete legacy and reflected theorem interfaces, not merely
the construction slice. It remains intentionally unlaunched while swap is
6.8/8.0 GiB used and the useful cumulative, focused, and PFT states occupy
about 75 GiB resident memory; another DMTCP restore would add about 18 GiB and
unnecessarily increase memory pressure.
