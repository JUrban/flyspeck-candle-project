## Question

The matched v3.95 gradient instruction measured a roughly 30-times recurring
gap between verified Word64 execution and an identical native calculation.
The original verified function built three short transient lists per box:

- ten directed product intervals;
- eleven signed lower-bound addends; and
- eleven signed upper-bound addends.

This experiment holds the pinned inputs, exact word operations, rounding,
overflow behavior, result digest, batch size, and 1,000-batch measurement
boundary fixed while removing those lists from the hot path.

## General refinement proof

CakeML commit `315aaab89` implements a direct fixed-arity path and proves:

1. its eleven-argument signed sum equals the original list fold;
2. its per-box result equals the original instruction for every input box;
3. its batch result equals the original batch for every input list, count, and
   digest; and
4. its final acceptance predicate equals the original predicate.

These are general HOL theorems, not checks limited to the 875-cell fixture.
Both implementations remain total: malformed list shapes and arithmetic
overflow return `NONE`.  The flat functions translate without generated
preconditions.  Verified x64 compilation succeeds.

Reusable stages cost 3m45s and 6.93 GiB peak RSS for translation/program-image
construction, then 5m23s and 7.51 GiB peak RSS for verified compilation.  The
already translated complete input image was reused.

The allocation hypothesis is therefore rejected as a material explanation of
the executor gap.  Fixed-arity source is not promoted into the full checker;
its general equivalence proof and benchmark remain isolated evidence.

Two earlier paired invocations completed all numerical runs but their
post-processing stopped on awk portability errors.  Those directories are
preserved with `failed-summary` names.  The accepted directory uses the
corrected runner; its run table contains seven complete alternating pairs and
no nonzero checker exits.

## Decision

This satisfies the bounded local optimization promised in v3.95.  No further
product-list, option-chain, or scalar micro-tuning is justified before the
integration measurement.

The next nonlinear implementation gate is the complete 875-cell compact
verdict using the existing total bounded arithmetic and authenticated delta
instructions.  It must charge:

- reusable input/program preparation;
- recurring numerical execution;
- every explicit overflow fallback;
- final compact bounds/verdict and theorem handoff;
- required repetitions and peak memory; and
- 875/875 certificate acceptance.

The measured target remains 22.58 seconds for a tenfold improvement over the
225.8-second reflected control.  The present per-instruction ratio is a
diagnostic, not a whole-checker projection guarantee.
