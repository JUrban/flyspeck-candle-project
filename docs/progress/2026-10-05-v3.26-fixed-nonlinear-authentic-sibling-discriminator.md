## Matched authentic discriminator

The existing reflected checker has two numerical propagation paths:

- fixed outer propagation, used by the current sibling discovery pipeline;
- fixed nonlinear propagation, whose general soundness and complete-checker
  handoff were proved earlier, but which had not been measured on the current
  sibling workload.

A bounded discriminator reused one exact encoded term containing the first
128 authentic function-1 cells from the third sibling batch. It computed a
per-cell verdict vector with each evaluator. Input preparation and encoding
therefore happened once and were excluded from both marked evaluation
intervals.

External UTC marker timestamps measured:

| Evaluator | Begin | End | Elapsed |
| --- | --- | --- | ---: |
| Fixed outer | 01:28:11 | 01:29:58 | about 107 s |
| Fixed nonlinear | 01:29:59 | 01:31:00 | about 61 s |

On this sample, fixed nonlinear is approximately **1.75x faster**. More
importantly, the complete verdict vectors agree:

```text
CANDLE_CV_FSN_DISCRIMINATOR_OK DEVELOPMENT_NON_RELEASE
  jobs=128
  outer_accepted=97 outer_rejected=31
  fixed_accepted=97 fixed_rejected=31
  differing_verdicts=0
  assumptions=0 axiom_growth=0
```

Both computations returned closed equality theorems whose left sides were
checked against the intended calls. The benchmark also checked that the
kernel axiom set did not grow.

The raw rate is about 0.84 seconds per cell for fixed outer and 0.48 seconds
per cell for fixed nonlinear. A linear projection over 13,978 cells would be
about 3.24 hours versus 1.85 hours, a saving of about 1.39 hours. This is a
planning estimate only: it is not a measurement of the live fourth batch,
and expression mix, garbage collection, and rejection shape may change the
large-run result.

## Interpretation

The experiment answers the first architectural question positively:
fixed-scale propagation through nonlinear instructions can retain the same
useful acceptance on authentic Flyspeck cells while removing a substantial
fraction of evaluator time. It is a much larger opportunity than the
seconds-level point-program or list-spine costs measured in v3.25.

The result does not yet justify replacing the current pipeline blindly.
The 128 cells use one authentic function and one contiguous region of the
third batch. Fixed rounding may be wider on other expressions or boxes, so a
larger retained batch comparison is still required. The active fourth-batch
lineage must also remain byte-for-byte unchanged until it completes.

The next discriminating step is therefore to run fixed nonlinear on the
retained complete 4,615-cell third-batch input and compare its verdict vector
with the already sealed fixed-outer scan. If acceptance remains equivalent
or any differences are tractable, future sibling discovery and complete
checking should use the already-proved fixed-nonlinear complete checker. The
current fourth batch will continue through its existing fixed-outer lineage.
