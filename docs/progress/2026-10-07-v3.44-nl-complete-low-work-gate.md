## Decision and next discriminator

The complete native gate rejects both current specialized formula lanes as
proof targets.  The block-rounding machinery remains available, but no new
Candle instruction theorem starts for a lane slower than the existing native
winner.

The historical specialized C++ batch is still 4.409 times faster than the
block fixed port.  The next bounded native experiment therefore changes the
rounding architecture, not another typedef: execute the same compact
historical data flow with direct outward rounding and no repeated fixed-scale
division, while retaining the full acceptance and boundary-quality gates.
That will separate global rounding cost from layout/control cost.

The separate approximately 15-fold encoded-Candle/native gap remains active.
Until a new numerical graph wins, the current generic fixed graph is the
baseline for compact instruction, evaluator-reuse, and machine-word/overflow
experiments.  The two gaps continue to be reported separately.
