## General logical boundary

Candle commit `17c4a57b` replaces the stable-program prototype's
action-296-only structural comparison with general HOL theorems about
certificate patching.

The new total state-passing operation traverses any supported analytic
expression and consumes proposed square-root intervals in the same postorder
as analytic compilation. It leaves existing certificate data in place if an
input is missing and returns surplus data explicitly. A checked caller must
therefore require both an empty remainder and the exact expected certificate
count.

The proof establishes, without hypotheses:

1. patching any expression preserves its certificate-erased analytic source;
2. patching an instruction list commutes with append; and
3. patching the compiled program is exactly compilation of the logically
   patched expression, with the same unused certificate remainder.

The result applies to every expression in the supported analytic language,
not only the current seven-square-root action-296 formula. It is the reusable
source-identity and compile-commutation bridge required by the architecture
review: per-box certificate numbers may become data without granting an
untrusted host transformation authority over instructions, topology, or
mathematical source meaning.

The focused test also instantiates the erasure theorem on the genuine
action-296 source, checks a nested two-square-root structural example, checks
that all general theorems are assumption-free, and verifies that the global
axiom set is unchanged.

## Remaining checked boundary

This milestone proves the logical transformation but does not yet authorize
the fast host-side byte patcher or a Flyspeck theorem. The next layers are:

1. an executable `cval` patcher that copies every non-square-root instruction
   unchanged;
2. a representation theorem equating that executable patcher with the
   logical state-passing operation;
3. an executable exact-count check, so missing and surplus payloads both fail
   closed;
4. a stable-program batch checker whose jobs contain only certificate and box
   data; and
5. one general acceptance theorem feeding the existing analytic, coverage,
   and live-Flyspeck handoff theorems.

Until those layers and a genuine action-296 theorem replay are green, the
current theorem-producing adapter remains the authority.
