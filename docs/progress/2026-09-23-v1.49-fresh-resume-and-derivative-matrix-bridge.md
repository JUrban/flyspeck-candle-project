## Restored-checkpoint input acknowledgement

The nonlinear predecessor restart wrapper now derives a per-run nonce from
the output directory, driver path, and driver SHA-256.  Its first fresh HOL
phrase prints:

```text

```

The wrapper requires that exact line once within 120 seconds, before any
driver marker can count.  Missing or repeated acknowledgement fails the run
early, while success produces an initial receipt and a final receipt recording
the acknowledgement and driver-marker ordering.  This distinguishes “the
restored toplevel consumed the new experiment” from “a process exists but is
still exposing old output.”
