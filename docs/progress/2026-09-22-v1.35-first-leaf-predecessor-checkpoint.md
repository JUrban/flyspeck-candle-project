## The previous closure-only boundary was too early

The v12 load was intentionally stopped after about ten minutes, before a
checkpoint or readiness claim. Its authenticated table contained the 90-node
nonlinear verifier closure but not the three exact source nodes needed for
genuine first-leaf reconstruction. Candle's source-identity and normalization
tables are configured once; a closure-only snapshot could not later load those
modules without a development-only table reset. Preserving v12 would therefore
have saved the expensive closure while still placing an avoidable identity
operation in every real-leaf experiment.

The preserved `ATTEMPT-SUPERSEDED` record identifies this boundary decision.
No source failure, semantic failure, or theorem failure occurred in v12.

## Two-tier disposable experiment loop

The next tier is prepared but cannot run until v13 is ready. One fresh v13
restore will load and test the existing proof-producing Taylor/split adapters,
load the phase-profile helper, and checkpoint again immediately before target
reconstruction. This pays stable adapter setup once without moving search,
Taylor construction, or proof into the reusable state.

The first disposable driver from that state uses the already bound exact
target and records separately:

- source reconstruction;
- non-search setup, certificate search, and adaptive validation;
- split-plan materialization;
- Taylor theorem construction;
- native leaf proof;
- reflected source planning, pre-compute proof work, `Kernel.compute`, and
  theorem handoff; and
- exact first-leaf center, width, function-bound, derivative-bound, and
  Hessian-bound terms for later arithmetic-only fixtures.

It requires the native and reflected leaf theorems to have the same closed
interface and the global axiom set to remain unchanged. This is a bounded
development mechanism, not a complete nonlinear or S3 result.

## Plan impact

The separation now matches the intended cost model:

- full closure and native reconstruction support: paid once;
- stable reflected checker/adapters: paid once in a child checkpoint;
- genuine search/Taylor capture: paid when a new representative certificate
  is needed; and
- numerical representation, whole-calculation, and theorem-handoff edits:
  run from disposable restored states or the smaller post-Taylor harness.

Full clean integration remains mandatory after a coherent candidate, but
small numerical experiments no longer require repeated hours-long closure
loads.
