## Concrete plan for the larger gap

The next integration gate remains the complete authenticated 167-instruction
program on all 875 genuine cells.  It will separately charge:

1. authenticated input/program preparation;
2. conversion into fixed-width words;
3. recurring numerical evaluation;
4. explicit overflow and exact-fallback frequency;
5. compact bound/digest/verdict production;
6. theorem handoff and any required repeated evaluation; and
7. peak memory.

It must retain 875/875 acceptance and the expected exact bounds.  The first
performance gate is **under 22.58 seconds**, a tenfold improvement over the
225.8-second reflected control.  Preparation is reported both cold and
amortized; it is not hidden from the comparison.

The implementation order is now constrained by that measurement:

- add the checked 128-bit dot and 192-bit weighted/Taylor completion over the
  compact state;
- add the supplied-certificate square-root boundary and the fixed inverse and
  arctangent scalar kernels;
- run the imported program with exact-identity dispatch for only the six
  proved delta roles; and
- compile one closed 875-cell checker returning only count, digest, bounds,
  fallback count, and verdict.

The complete profile then selects the next experiment:

- if list/state traversal or evaluator dispatch dominates, compare the same
  exact operations and rounding in a fixed tuple/array or compiled straight-
  line program representation;
- if inverse/root/arctangent work dominates, compare one genuinely different
  low-work numerical kernel against the generic kernel while holding the word
  backend, Taylor completion, boxes, rounding, and final acceptance fixed;
- if theorem handoff or repeated evaluation dominates, change the compact
  verdict boundary rather than the numerical algorithm; and
- in every case, confirm the winner on a second real expression family before
  broadening its proof.

This keeps specialized numerical algorithms as a live architectural target,
while making the next choice depend on a complete verified-batch profile
rather than on a fast but unrepresentative leaf.
