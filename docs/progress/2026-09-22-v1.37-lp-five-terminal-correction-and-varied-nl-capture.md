## The two-terminal LP break-even claim is withdrawn

The v1.36 report extrapolated a three-terminal break-even from terminals 8 and
10. The exact five-terminal family, terminals 8--12 from `hard_2.dat`, does
not reproduce that terminal-level advantage:

| measurement | legacy terminal phases (s) | computed terminals (s) |
|---|---:|---:|
| direct-congruence run | 103.30 | 99.26 |
| list-correspondence run | 94.44 | 97.69 |

The speed difference changes sign between otherwise comparable runs. It is
therefore treated as allocation/GC/run variation. There is currently no
measured finite break-even for the complete architecture, and the earlier
three-terminal claim is explicitly superseded.

Both five-terminal runs preserve the exact theorem conclusion, hypothesis
set, theorem digest, and global axiom set for every terminal. The family has a
610-variable union basis and a 1,662-row deduplicated master.

## One generic source-denotation theorem reduces master cost

The isolated branch `codex/cv-lp-sparse-list-correspondence-v1`, commit
`0557013b457230be9f16d86933621ae8e437e630`, replaces arithmetic expression
reconstruction for every row with:

1. a recursive HOL function that decodes sparse entries to the original
   `(coefficient, variable)` list;
2. one induction theorem equating the sparse vector denotation with `lin_f`
   of that decoded list; and
3. concrete list/pair congruences that authenticate each decoded row against
   its source theorem.

The focused suite passes, including exact theorem equality, wrong-index
rejection, hypothesis preservation, and unchanged-axiom checks. Candle's
frontend required the two recursive-definition clauses to be typechecked
separately and combined with `mk_conj`; this is a bounded source-level
workaround and does not change the theorem statement.

Measured on the same five real terminals:

| phase | direct congruence (s) | list correspondence (s) | change |
|---|---:|---:|---:|
| computed source plan | 43.50 | 42.30 | -1.20 |
| selector/shared context | 25.05 | 25.17 | +0.12 |
| authenticated master table | 220.28 | 184.37 | **-35.90** |
| terminal plan construction | 1.12 | 1.07 | -0.05 |
| five computed terminals | 99.26 | 97.69 | -1.57 |
| complete computed cold path | 389.20 | 350.59 | **-38.61 (9.9%)** |

The master-row theorem phase itself falls from 219.31 to 183.41 seconds,
**16.4%**. This validates list-level correspondence as a useful structural
step, but the 350.59-second computed cold path is still 2.97 times the
117.91-second colocated legacy batch.

The result narrows the next LP boundary. External basis/index/sparse planning
is already cheap and can remain untrusted. The expensive remaining work is
constructing 1,662 individual source-denotation theorems. The next prototype
should check the complete encoded master/source correspondence through one
computed predicate and a general soundness theorem, while retaining exact
source hashes, row selection, hypotheses, final theorem interface, and
fail-closed rejection of malformed plans.
