## Exact result

CakeML commit `be826f58b` adds
`compute_boundedCase16594WordDirectTopologyRefinementScript.sml`.  It proves:

1. a direct compact-list length evaluator theorem;
2. an evaluator theorem for two already-evaluated application arguments;
3. exact lookup and unfolding of the ordinary compact-join body; and
4. by structural induction, equality between that ordinary source evaluation
   and `bounded_case16594_direct_boxes_join` for arbitrary well-formed compact
   box lists and sufficient clock.

The explicit relation rejects malformed interval/list shapes and requires the
two nonempty lists to have matching structure.  The proof therefore does not
authorize basename aliases, malformed encodings, or a captured genuine-data
shortcut.  Its recursion is generic in the interval endpoints and list
length.

The proof was first closed in a live scratch theory and then transcribed into
the source theory.  The only build failures were immediate static namespace
qualifications; no evaluator timeout, heap escalation, or semantic exception
was used.
