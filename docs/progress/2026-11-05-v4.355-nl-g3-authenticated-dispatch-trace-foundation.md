## Certificate-cursor design decision

The old first-ten-instruction proofs split the concrete runtime certificate
list by hand.  Extending that pattern to all 31 certificate-consuming
instructions would duplicate payload facts and create a maintenance hazard.

Inspection of the proved word-to-object refinement gives a smaller scalable
route:

- inverse emits the two encoded certificate fields already present in the
  typed certificate;
- square root emits its five typed certificate fields; and
- atan emits eight runtime intervals.  Four come from the typed atan
  certificate, while its already-proved refinement theorem names the input,
  result, and square intermediates needed for the other fields.

The next proof object will therefore be a word-level packet-emitting trace.
Its projection is the existing successful fixed-word execution, and one
closed authenticated equality will connect its 134 emitted intervals to the
real cell-0 runtime stream.  The object proof then consumes the existing
generic cursor theorems.  This avoids a new certificate datatype and avoids
31 handwritten concrete split proofs.
