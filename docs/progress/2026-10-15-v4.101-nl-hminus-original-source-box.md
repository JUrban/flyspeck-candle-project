# v4.101: original Flyspeck `hminus` source box proved

Date: 2026-10-15 UTC

Status: DEVELOPMENT / NON-RELEASE

## Headline

Candle now proves a positive-width box for a real Flyspeck source expression
containing `hminus`, first with the seven-dimensional reflected analytic
checker and then as an assumption-free theorem about the original
six-dimensional function.  The general append-parameter theorem successfully
uses Flyspeck's proved `hminus` enclosure to remove the checker-only seventh
coordinate.

This is an original-source theorem and an important expression-family result.
It is not yet a complete `hminus` certificate, a complete inequality, or an
all-NL run.

## Result

The regression reconstructs function 1 from
`prep-GLFVCVK4 2477216213 split(0/64)` through the direct `Break_case_exec`
source path.  It replaces only `hminus` by the seventh vector coordinate,
prepares tight square-root enclosures over the actual box, and executes the
universal analytic checker on a strict subbox of the authenticated source
domain:

- the top `1/64` of source coordinate 1;
- the bottom `1/256` of source coordinates 2 through 6;
- the complete interval established by Flyspeck's `hminus_interval` theorem.

Both results are assumption-free:

1. the seven-dimensional computed theorem over the parameter box;
2. the bridged theorem for the original six-dimensional Flyspeck expression
   containing the exact `hminus` constant.

The reconstructed program has 46 instructions.  The regression derives the
checker endpoints from the conclusion of `hminus_interval` and normalizes only
those endpoints.  This avoids both an unsafe hard-coded approximation and the
unnecessary broad theorem conversion that killed an earlier disposable test
process.

## Coverage clarification

The 96.2% figure in v4.100 is a conservative source-level weighting: it counts
all selected leaves belonging to a source ID whenever any disjunct of that
source has a residual head.  It is not a direct count of leaves whose selected
function actually contains that head.  In particular, the first inspected
leaf under the `hminus`-tagged source selected function 0, while `hminus`
occurred in function 1.

This does not make the residual work disappear.  Adaptive certificates may
select any source disjunct, so all disjuncts still need structural and
proof-producing support.  It does mean the earlier residual-leaf counts must
not be described as exact selected-function counts.

## Supporting changes

- Whole-box square-root preparation is dimension-generic and now exposes a
  seven-dimensional entry point.
- Exact decimal endpoints are accepted and normalized without routing them
  through binary-float conversion.
- The source probe exposes its reconstructed expression list so the regression
  checks the real source expression rather than a hand-copied formula.
- Focused regressions cover exact decimal endpoint encoding and the complete
  seven-to-six-dimensional `hminus` theorem handoff.

## Remaining boundary

The next `hminus` milestone is to replay domains produced by the real adaptive
certificate tree and hand the resulting theorem to `m_cell_pass`, then repeat
that path over the relevant source/disjunct family.  After that, the material
source-language residual is `matan`; the small `asn`/`acs`/`arc_hhn` family
also remains.

Beyond expression coverage, all NL still requires complete certificate-tree
execution, compact fast checker-to-theorem handoff, original theorem assembly,
batch throughput validation, and a clean checkpointed corpus run.
