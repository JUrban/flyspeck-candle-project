# `audit1.md` response and direct-runner hardening — 2026-08-28

## Outcome

I read `audit1.md` in full and accept its central criticism: the PFT route is
useful as an oracle and engineering diagnostic, but it cannot establish the
v1.3 S2/S3 direct-source obligations.  The direct compiled route therefore
remains primary.  Candle integration commit
`d5f831ede13be1173c064a982f0eb52d3ab6fa14` responds to an additional
independent review of the first cumulative-runner implementation and
strengthens the nonlinear closure contract.

The two critical runner defects are closed:

- the runtime no longer trusts a self-consistent host plan.  It independently
  reconstructs the complete plan, all eight prefixes, materialization, and
  input bindings from the pinned manifest/full driver, then requires exact
  object and byte equality;
- the runtime emits the exact ordered 39-file
  `candle_flyspeck_lp_certificate_files` provider required by normalized
  `verify_all.hl`.

The runner also uses fresh nonce-bound exact-line events, so quoted or prefixed
source text cannot satisfy a marker.  It snapshots every runtime-consumed
source, normalization, generated input, linked artifact, harness file, process
input, and selected prefix into a disjoint read-only attempt tree; each copy is
checked against independently authenticated bytes and the whole inventory is
rehashed after execution.  Generated control inputs are read-only and rehashed
too.  Process groups are terminated and reaped on timeout, signal, or runner
exception, and receipts are finalized atomically once launch has begun.

After every exact outer `#flyspeck_needs` action, an in-process checker now
requires the next planned index and identity and accepts only an unchanged
logical ledger for a loader skip or exactly the expected identity consed onto
the prior ledger for a load.  The boundary requires the complete ordered event
sequence.  This is materially stronger than eventual membership, but it is
still not a loader-owned trace of every ordinary nested `needs`/`loads` event.

## Nonlinear coverage

The previous 23,242 check is retained but correctly labeled only as a
partition-shape diagnostic.  The normalized reconstruction now counts all
7,479 pinned serialized `Iarg_leaf` visits, rejects `TRUTH` sentinels from both
caught reconstruction paths, and keeps both theorem-surface comparisons fatal.
These gates are necessary but do not independently bind proof history or rule
out a count-preserving mutation; compiled execution, structural identities,
axiom accounting, and clean repetition remain required.
