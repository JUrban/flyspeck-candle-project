## Reflected acceptance is now proved

Candle commit `208c99b` closes the reflected numerical acceptance boundary.
The executable checker returns both a Boolean verdict and the exact computed
Taylor upper. Its correctness theorem identifies both outputs with the
ordinary definitions. The final theorem
`candle_q_dim_poly_jet_whole_box_accept_sound` states, for every supported
dimension-valid source expression and valid box, that numerical acceptance
implies the original expression is strictly negative at every point of the
box.

This is the intended proof-producing architecture: intermediate intervals
remain data inside `Kernel.compute`, while one reusable theorem converts an
accepted result to the source inequality. No expression-specific calculus
proof is required.

## Hessian-free center evaluation is universally proved

The whole-box contract needs the center value and gradient, but it does not
use the center Hessian. The prior implementation nevertheless constructed all
36 center-Hessian intervals in six dimensions and then discarded them.

Candle commit `7277978` adds a first-order reflected evaluator whose state is
only `(value, gradient)`. It proves primitive, instruction, stack, complete
program, and representation correctness. In particular,
`candle_cv_q_dim_first_jet_program_projection` proves for every encoded
program and interval environment that the new evaluator is exactly the
value/gradient projection of the already-proved full jet. This is universal,
not a benchmark-specific output comparison.

The production development checker now uses:

1. the first-order evaluator at the box center; and
2. the original second-order evaluator over the complete box for the Hessian
   enclosure.

The source theorem, hypotheses, final numerical upper, and strict-negativity
interface remain unchanged.

containing every repeated monomial of degrees two through five. Its 4,859
instructions were encoded once into 38 chunks and checked consecutively on
the narrow binary, asymmetric prime-denominator, and wide binary boxes.

The comparison below uses the prior full-center run `v3` and exact-commit
optimized run `v7`. The totals include reusable encoding/preparation and all

## Plan impact

The experiment materially changes the optimization priority. Eliminating the
unused center Hessian is safe, general, and nearly halves the measured
degree-five batch. Preparation, theorem handoff, rational growth, and memory
remain secondary. The unchanged full-box Hessian traversal now dominates the
recurring check, taking roughly 11.6--13.6 seconds per box in this workload.

The next bounded performance work should therefore profile and reduce that
full-box traversal while preserving its universal enclosure theorem. Useful
possibilities include avoiding redundant symmetric Hessian work or reducing
repeated vector/matrix traversal, but neither should be adopted without a
proved representation contract and measured batch benefit. The genuine
captured Flyspeck leaf and legacy comparison remain the required integration
test once the authenticated predecessor emits its readiness receipt.
