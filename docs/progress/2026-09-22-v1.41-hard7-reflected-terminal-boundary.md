## Exact real terminal result

The current sparse reflected/numeral-cache checker was run against terminal
2,128 of the real 9,080-terminal `hard_7.dat` certificate. The run restored a
fresh copy of the clean post-action-183 checkpoint and executed the legacy
and reflected proofs in the same process.

Both paths passed the exact gates:

- the same final conclusion and hypothesis multiset;
- `equals_thm` theorem identity;
- the expected rendered-theorem digest;
- the expected selected-row digest;
- unchanged global axiom set; and
- exact authenticated prototype/source identities.

The terminal used 486 constraint rows, 345 selected auxiliary rows, 513
variables, and 146 hypotheses. The two proof paths measured:

| terminal-2,128 phase | wall time (s) |
|---|---:|
| legacy complete terminal | 21.99 |
| sparse reflected complete terminal | 111.67 |
| reflected / legacy | **5.08x slower** |

The reflected path breaks down as follows (nested phases are not additive):

| reflected phase | wall time (s) |
|---|---:|
| row selection | 0.66 |
| terminal number conversion | <0.01 |
| source variable discovery | 1.27 |
| selector proof preparation | 15.79 |
| row reification | 71.46 |
| complete source-number/correspondence conversion | 87.26 |
| source proof preparation | 5.98 |
| `Kernel.compute` | 17.11 |
| final theorem handoff | 0.05 |

This is a decisive negative result for replacing the legacy checker with the
current per-row reflected architecture. The evaluator and final handoff are
not the main problem: source-row reification and correspondence proof
construction dominate, and the complete reflected terminal is more than five
times slower even before charging reusable cold setup.

No prototype source is integrated from this experiment. The next plausible
LP boundary remains a coarse checked table/source correspondence theorem that
can be prepared once and reused across many terminals. Further local
per-entry relation or congruence variants are not justified by the measured
results.

## Harness observation

The experimental source exposed three large top-level decoded values, causing
264 MB of diagnostic output before and around the profiled terminal. Those
prints are outside the legacy/reflected phase comparison and did not affect
the exact proof gates, but a future batch harness should keep decoded state
inside a discarded-result/local binding. This avoids I/O noise without
changing the checked terms.
