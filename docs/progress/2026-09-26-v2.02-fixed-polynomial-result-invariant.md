## Universal analytic milestone

Candle commit `971142d` establishes the dimension-generic semantic invariant
for a completed fixed-scale polynomial result.  The new
`candle_fs_result_poly_invariant` contract states that, whenever the computed
domain verdict is true:

- the converted center jet has the right shape and contains the polynomial's
  value, gradient, and Hessian at the authenticated box center; and
- the converted Taylor proxy has the right shape and contains the same
  polynomial value, gradient, and Hessian at every point in the box.

`candle_fs_result_complete_poly_invariant` proves this contract from checked
center-jet data, checked whole-box Hessian enclosures, polynomial validity,
and authenticated box geometry.  It combines the previously proved fixed
value and gradient Taylor bounds with the existing Hessian enclosure.  The
result is general over the supported polynomial language and dimension; it
does not introduce a separate calculus proof for each expression.

Two structural bridge lemmas recover complete gradient and Hessian list
containment from the public pointwise jet predicate.  This keeps the
arithmetic implementation hidden behind the established dimension-generic
jet interface.
