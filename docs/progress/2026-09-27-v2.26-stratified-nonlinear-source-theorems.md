## Consequence

The next coverage step should avoid writing another batch-specific proof
architecture.  The current data-driven pattern is sufficient for a bounded
sequential/chunked forest runner:

1. discover direct/one-split/depth-two policies over bounded genuine-leaf
   chunks while retaining only one parent family at a time;
2. materialize the selected forest as ordinary plan data;
3. recheck only its final cells through the existing universal reflected
   theorem; and
4. validate original root identities and aggregate theorem digests per chunk.

This is the practical route toward all 1,061 action-296 precision leaves.  It
also preserves the performance-note conclusion: source/plan preparation is
still material, so future chunks should measure and, where possible, reuse
that work rather than focusing on already bounded GCD-fuel or evaluator-setup
micro-costs.
