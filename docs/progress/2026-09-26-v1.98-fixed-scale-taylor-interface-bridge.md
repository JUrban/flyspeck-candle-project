## Research-note assessment

The source observations in
`docs/advice/Candle_NL_Performance_Research_2026-09-25.md` usefully separate
several possible costs.  The evidence now ranks them as follows:

1. Rational normalization/GCD work is a measured recurring bottleneck.  The
   fixed-scale backend reduced the 64-distinct-box recurring calculation from
   105.14 seconds to 13.10 seconds, an **8.03x** speedup, with all 130 checked
   complete outputs exactly matching the rational backend.
2. Source preparation, box setup, and per-call evaluator setup are material,
   but the existing internal batch already amortizes them.  They explain cold
   and small-call cost, not the measured recurring arithmetic gap.
3. Compact batching is already covered.  Full intermediate results remain
   useful for equivalence testing, but the final checker can keep them inside
   the computation and return a compact verdict.
4. Constant/sparse specialization, discarded value/gradient work when only a
   Hessian is used, duplicated endpoint products, and proof-producing
   untrusted hint arithmetic remain plausible residual costs.  They have not
   yet been shown to dominate the proved integrated path.

The next targeted experiment should therefore be a warm, prepared batch on
the genuine checker, comparing compact verdict and full diagnostics while
counting accepted subdivisions.  If evaluator work still dominates, a
constant/sparse case and a Hessian-only case are the cheapest discriminators.
This avoids optimizing source-level candidates before the complete proof path
can measure them.
