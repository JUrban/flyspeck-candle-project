## Interpretation of the two gaps

On this graph, comparing the new 0.746-second exact diagnostic with the
previous 0.524-second padded-hardware lane leaves about **1.42 times** for
exact representation plus rounding.  This does not prove that a word checker
will attain that ratio, but it shows that generic multiprecision endpoint
objects account for a material part of the previous native arithmetic gap.

The historical approximately 340-times comparison remains a useful starting
architecture diagnosis, not the current residual on case10173.  Controlled
native work has already reduced that particular fixture's optimized numerical
residual to about 1.35 times.  The large open case16594 boundary is now the
combination of:

1. a current reflected batch of about 225.8 seconds;
2. a source-authenticated exact native target of about 0.746 seconds after
   the positive delta and endpoint-representation changes; and
3. a compiled verified operation-count trace of 6.34 seconds that does not
   yet carry the actual 875-cell data flow.

The roughly 303-times reflected/native ratio is therefore not assigned to one
cause.  It includes algorithm work not yet integrated into the reflected
checker, encoded execution, conversion, and theorem handoff.  The 6.34-second
trace suggests that most encoded scalar-operation overhead can be removed,
but an actual-data theorem-producing run is required before claiming that
speedup.

## Bounded proof and implementation decision

The analytic specialization proof remains bounded to the two positive general
families:

- `4*x_i*delta`; and
- `-d(delta)/dx_j`.

The rejected inverse-root and whole-chain variants do not re-enter the proof
plan.  No proof is started for the native `__int128` diagnostic itself.
Instead, the result strengthens the already selected total word route:

1. represent bounded endpoints and 192-bit accumulators by explicit words;
2. return overflow as data and use the unchanged exact fallback;
3. convert the authenticated batch once rather than wrapping every endpoint
   in a general natural-number object;
4. execute the actual 875 jobs and return only the compact bounds/verdict
   needed by the universal analytic theorem; and
5. require byte-identical bounds, 875/875 acceptance, and a fully charged
   recurring time below the existing 22.58-second tenfold gate.

After that gate, the same executor and the two general analytic instructions
must pass a second genuine expression family before broader proof investment.
This keeps the local proof packet small while directing the substantial work
toward the measured orders-of-magnitude boundary.
