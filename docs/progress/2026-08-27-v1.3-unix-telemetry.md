## Semantic boundary

This intentionally differs from OCaml wall-clock behavior.  It is safe only
for the exact selected consumers:

- the wrapped function or certificate verifier is evaluated unchanged;
- effects, exceptions, and proof/result values are unchanged;
- only the difference of the two timestamps becomes zero;
- the selected consumers use that difference only as top-level test output or
  the `Total verification time` report.  LP theorem construction flattens the
  independent first projections.

The external release runner remains responsible for structured wall time and
RSS evidence.  Semantic fingerprints exclude timing text and include theorem,
definition, hypothesis, and assumption content.  Any additional selected clock
consumer reopens the ledger entry rather than inheriting this justification.
