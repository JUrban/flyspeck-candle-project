## Required directive semantics

`#flyspeck_needs` is deliberately not ordinary `needs` and is fail-closed in
the current compiled Candle.  Its required future loader action is atomic:

1. resolve only the manifest-selected source for that entry;
2. if it is not already loaded, evaluate it at that exact input position;
3. only after successful evaluation, call
   `State_manager.neutralize_state ()` exactly once;
4. if the entry is already loaded, perform neither evaluation nor
   neutralization; and
5. abort on malformed, unknown, reordered, unresolved, hash-mismatched,
   failed, or unsupported dynamic loads.

These rules preserve strictbuild's successful-load and duplicate behavior.
They also exclude both unsafe shortcuts identified during the top-level
runtime audit: erasing the calls and providing a successful no-op dynamic
loader.

The current Candle REPL has a separate correctness bug: it treats any
level-zero `needs` token as a directive, including a token in an expression or
definition.  The new directive is intentionally distinct so its later parser
work can require an exact statement shape without broadening that behavior.

Loader commit `c3336d58e0e9a15ecb08c0bf43eb200b0b71be8d` then adds
in-process authentication: before `strictbuild`, the direct loader requires the
program to exist and have the generated contract's exact MD5.  The outer
release lock independently pins its SHA-256.  This authentication does not
activate `#flyspeck_needs`.

## Remaining boundary

The driver is not yet loaded by `flyspeck_loader.ml`.  Activation requires the
compiled Candle input stack to implement the exact directive action, distinguish
definitions such as `let needs s = ...` from directives, and handle selected
literal dependency calls in place.  The original strictbuild definitions must
still parse and type; accidental dynamic `Toploop.use_file` calls must continue
to fail closed.  Compiler-internal uses in ssreflect and serialization remain
the separate typed-registry versus verified-evaluator decision recorded in the
top-level runtime frontier.
