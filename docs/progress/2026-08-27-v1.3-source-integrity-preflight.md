# v1.3 source-integrity preflight

## Outcome

Loader commits `9a161801b00908d4468af0d78fe92e73cde2ee02` and
`76331264d60e0769fceaa1c22454e96414d9d28c` make the direct loader reject
selected-source corruption in-process before it evaluates
`build/strictbuild.hl`.  The manifest generator now emits
`candle/flyspeck_source_digests.ml` with 398 `(repository, path, MD5)` rows.
The JSON manifest pins every node with both SHA-256 and OCaml-compatible MD5,
and pins the generated program itself as
`0af74c3dab90d8c37234a07b55c632257dcced97fa7fca924fa5fb8f6bc362ab`.
The complete JSON manifest is
`a26f155bc8f34fae1f29906de7cbd4f1e53e2cd0ff96e01bbb0810d484bc67d1`.

The generated digest program is an explicit generated dependency rather than
a self-hashed graph node.  The only omitted row is the executing loader, which
is pinned by the outer release lock; this breaks the self-hash cycle.  Before
executing the generated program, the loader checks its embedded expected MD5
`552a21f448e866a7f8fcd49ce8908c2f`.  Candle then loads a small shared integrity
checker, requires exactly 398 rows, resolves each row beneath the
manifest-supplied Candle or Flyspeck root, rejects missing files and unknown
repositories, and compares `Digest.file` values before continuing.

## Evidence

- Nineteen manifest tests pass, including generated-program identity, exact
  graph coverage, MD5/SHA-256 shape, loader placement, and fail-closed source.
- A complete clean-source regeneration passes with 297 roots, 399 source nodes,
  418 dependency edges, and 42 generated mathematical inputs.
- The compiled Candle gate hashes all 398 listed files successfully and then
  rejects an intentionally wrong `hol.ml` digest with the exact mismatch.
- The compiled non-full guard still fails before source loading.
- The integrated full-mode loader passes the new preflight and still stops at
  the known `strictbuild.hl` `#load` compatibility frontier; it does not claim
  full execution.

Adding the checker and pre-execution program authentication contributes four
real `Digest` calls, so the selected compatibility inventory was correctly
expanded from 13 to 17 qualified uses.

## Claim limit

This is a preflight over the selected on-disk graph, not yet a sandboxed file
open primitive.  `hol.ml` and the loader begin loading before all in-process
checks can finish; release authentication must pin the executable and these
bootstrap sources externally.  The generated digest program is authenticated
before it executes.  The current preflight
also does not yet authenticate generated LP/nonlinear data at the exact point
of consumption or provide resumable theorem-state checkpoints.  No S1/S2/S3
milestone is advanced by this gate alone.
