## Question

The first fixed-hybrid sample accepted only one of eight genuine action-296
certificate leaves when all eight shared one local-envelope box certificate.
This work separates two possible causes:

1. loss of bound tightness from sharing one certificate across too broad an
   envelope; and
2. genuine additional subdivision required by the reflected centered checker.

All experiments use exact domains from the real 1,061-pass-leaf precision
tree.  They are diagnostics: computed theorems are assumption-free, but the
flag lists are not used as release or full-certificate evidence.

## Combined interpretation

Across the **20 sampled genuine leaves**, seven pass directly and all thirteen
rejections close after one suitable binary split.  The resulting sample has
33 reflected cells for 20 legacy leaves, a **1.65x** cell-count factor.  The
sample is deliberately distributed but is not a statistical proof about all
1,061 leaves.

The evidence changes the immediate diagnosis:

- bound tightness is a real cost, but there is no sampled evidence of the old
  64-way subdivision runaway;
- a fixed split coordinate is insufficient, while a cheap untrusted adaptive
  axis proposal is compatible with the existing checked-data architecture;
- local certificate grouping can substantially amortize source preparation,
  but group size must respect enclosure tightness; and
- per-box variant construction remains nearly linear in the number of final
  cells and is now at least as important as shaving fixed evaluator setup.

The next architectural step is not a new analytic theorem.  It is a compact
adaptive tree job format beneath the already proved batch/tree soundness
boundary: untrusted preparation proposes local certificate groups and split
axes, one computed verdict checks all final cells, and the exact cover theorem
reconstructs the root result.  Before scaling that path to all 1,061 leaves,
the remaining fixed-hybrid numerical cost should be profiled on accepted final
cells, especially the rational inverse, square-root, and arctangent steps.
