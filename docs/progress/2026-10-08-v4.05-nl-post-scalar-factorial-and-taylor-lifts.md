## The broader native investigation remains active

The earlier complete 2-by-2 factorial already separated generic
derivative/Taylor work from endpoint representation.  Repeating it unchanged
would not answer a new question.  The new experiment instead holds the latest
fixed square-root, reciprocal, and range-reduced arctangent kernels constant
in all four lanes, then crosses only:

1. the generic source graph versus the authenticated delta radicand and
   derivative instructions; and
2. checked Boost 128-bit endpoints versus built-in 128-bit endpoints.

Every lane uses the same authenticated 167-instruction case16594 expression,
all 875 genuine boxes, `2^40` scale, directed shift rounding, sign-classified
interval products, checked 192-bit Taylor accumulators, supplied
certificates, and final acceptance predicate.

## Concrete route to the orders-of-magnitude objective

The next decision point remains one complete checked-word Candle batch, not
another scalar specialization:

1. add constant, variable, negation, addition, multiplication, and source
   program dispatch over the existing compact Taylor state;
2. integrate the translated reciprocal, square-root, and arctangent lifts and
   dispatch the six already proved delta identities only after exact program
   authentication;
3. execute the actual 167-instruction program over all 875 boxes and return
   only compact bounds, digest, fallback count, and verdict;
4. charge cold/reusable preparation, conversion, recurring evaluation,
   fallback, result production, theorem handoff, required repeats, total
   elapsed time, and peak memory;
5. require 875/875 acceptance and the authenticated expected bounds, with
   22.58 seconds as the first tenfold gate against the reflected control; and
6. validate the resulting architecture on a second genuine expression family
   before broadening its proof surface.

The post-scalar profile makes the next substantial alternative concrete.  If
the complete Candle profile confirms that generic multiplication, repeated
Taylor completion, list traversal, or dispatch dominates, compare the same
word arithmetic and outward rounding in an authenticated fixed-layout plan:
compact six/21 arrays or tuples, coarse straight-line blocks, and a small
vocabulary of generally proved fused jet instructions.  The first candidate
is a general square/product block, not another per-expression rewrite.  It
must preserve complete-certificate acceptance and enclosure quality.  A
single plan-compiler simulation theorem and one compact batch soundness
theorem are the intended proof boundary.

This keeps specialized numerical algorithms active as a larger architectural
target while bounding the current scalar proof work.  Preparation may be
substantial and is reported separately; complete-batch elapsed time and
certificate acceptance remain the deciding measures.
