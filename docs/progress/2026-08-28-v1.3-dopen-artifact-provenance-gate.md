## Bootstrap record

`candle/cakeml_artifact_provenance.py record-bootstrap` derives the expected
CakeML and HOL4 revisions from the authenticated direct manifest.  It rejects
a dirty or mismatched worktree, a missing or unsuccessful bootstrap transcript,
or a missing generated input.  Its JSON record binds:

- CakeML `936219bbc3021fa20418d62e85155f2d0092b9f9` and HOL4
  `a390cbabd3a4521bab4ee20281e3e42933a8a3ae`;
- the direct manifest SHA-256;
- the exact `Holmake -j1 cake.S` command and transcript hash; and
- byte counts and SHA-256 identities for `cake.S`, `config_enc_str.txt`,
  `candle_boot.ml`, `basis_ffi.c`, and `Makefile`.

`build-local-cakeml.sh` now requires this record as a second argument and
revalidates every field before copying any ignored bootstrap output.

## Linked and runtime record

After patching and linking, the build requires `cake --version` to report the
same CakeML/HOL4 revisions and emits
`candle/build/cakeml-build-provenance.json`.  That record binds the clean Candle
commit, external bootstrap record, assembly patch, linked executable, patched
assembly, copied inputs, generated `types.txt`, and generated `insulate.ml`.

Both the synthetic Dopen runtime smoke and the bounded real-source Dopen prefix
gate validate the complete linked record before starting Candle.  A dirty or
mismatched Candle checkout, missing external record, modified output or patch,
wrong embedded revision, or executable/version-output hash drift fails before
the semantic workload.

## Host validation and remaining acceptance

Four focused provenance tests cover exact manifest pins, file tamper rejection,
version extraction, and ambiguous-version rejection.  Python compilation and
shell syntax checks pass; the complete Candle host suite passes 79 tests.

These are host-side enforcement tests only.  The project ledger remains
`proof_pending`: the active verified bootstrap must finish, its record must be
created and revalidated, the linked binary must pass both Dopen runtime gates,
and the corpus-derived result must still be compared against its pinned
reference semantics before G2 can advance.
