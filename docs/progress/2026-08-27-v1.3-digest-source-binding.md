## Pure implementation

`candle/ocaml.ml` implements MD5 over virtual padding, avoiding a second padded
copy of the input.  The 64-round constants use CakeML's verified array basis;
32-bit arithmetic is explicit mask/shift/rotate logic over CakeML integers.
`Digest.file` reads through verified TextIO, closes the channel on both success
and failure, and returns the same raw 16-byte digest representation as OCaml.
`to_hex` validates that representation before lower-case conversion.

`compare` is also source-backed for the supported compatibility surface,
although it is not selected by the current execution graph.
