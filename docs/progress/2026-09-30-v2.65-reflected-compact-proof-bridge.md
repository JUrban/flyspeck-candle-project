## Result

Candle commit `c3ca8d72f9880a313e1f6a2370a1337b5e0472a1` is pushed on
`codex/cv-nonlinear-disjunctive-v1`. It closes the proof gap identified in
v2.64 for the reflected compact topology prototype.

The new universal theorem proves, for arbitrary logical token streams, raw
job lists, dimensions, and starting stacks, that the reflected `cval` runner
returns exactly the encoding of the existing logical compact runner. Separate
injectivity theorems cover booleans, interval lists, raw job lists, active
root stacks, and complete compact results.

A reusable proof-producing adapter now:

1. authenticates the canonical raw job representation;
2. executes the box-free topology stream in `Kernel.compute`;
3. connects the computed result to the logical compact runner once;
4. invokes the existing analytic compact soundness theorem once; and
5. returns the existing source-level theorem interface.

On four genuine case-16594 cells and seven exact postorder tokens, the adapter
returned a source theorem with zero assumptions and no axiom growth. Unlike
the v2.64 discriminator, this result now earns proof credit within the
development lane.

## Matched performance

The measurements below begin after the four numerical Taylor jobs have
already been accepted, so they compare the topology/proof paths on the same
real data.

| Path or phase | Wall time |
|---|---:|
| existing native compact step | 41.314 s |
| latest complete reflected proof path | **17.043 s** |
| reflected proof path, preceding confirmation | 18.427 s |
| reflected topology computation alone, latest | 1.268 s |

The complete reflected proof path is therefore **2.24--2.42x faster** than
the matched native compact step in these two confirmations. The earlier
36.9x topology-only result did not include representation authentication or
the final analytic theorem handoff; the smaller end-to-end factor is the
correct current engineering metric.

The latest 17.043-second path breaks down as follows:

| Phase | Wall time |
|---|---:|
| canonical job identity check | 2.484 s |
| reflected topology compute | 1.268 s |
| canonical root identity check | 2.891 s |
| complete theorem handoff | 10.399 s |

The theorem handoff itself contains:

| Handoff subphase | Wall time |
|---|---:|
| reflected/logical correspondence | 0.862 s |
| expected-result encoding | 0.862 s |
| result injectivity | 1.268 s |
| analytic soundness composition | 7.404 s |

The analytic soundness total is mainly one reusable theorem instantiation
over the concrete expression and job batch (5.221 s), followed by `MATCH_MP`
(1.268 s) and the source rewrite (0.913 s). It is paid once for the whole
bounded stream, not once per leaf.

## Discriminating optimization

The first proof-producing version used a generic `REWRITE_RULE` to replace
the token, job, and stack representations throughout the correspondence
theorem. Profiling measured 12.227 seconds in that subphase and 20.656 seconds
for the full handoff.

Replacing it with four explicit congruence links reduced correspondence to
0.862--1.218 seconds, a **10.0--14.2x** improvement, and reduced the full
handoff to 10.399--11.067 seconds. This confirms that broad theorem traversal,
not the reflected evaluator, was the principal avoidable bridge cost.

## Fail-closed coverage

The universal proof covers all runner states, including rejection branches.
The genuine fixture also has executable adversarial checks. Candle rejected:

- a noncanonical leaf tag;
- a glue token with a nonzero marker;
- an out-of-range axis;
- a wrong but in-range split axis;
- a glue token with a missing branch;
- changed sibling boxes that violate the exact split; and
- a stream boundary with unconsumed jobs.

The last runner call correctly returns success for the empty token stream but
retains the unconsumed jobs; the proof adapter detects and rejects that result
at its complete-consumption boundary.

## Decision and next boundary

The architecture has crossed the important boundary: the fast reflected
topology is no longer merely a behavioral discriminator; it returns a compact
kernel theorem through the existing analytic soundness interface.

The next performance work should remain evidence-driven:

1. expose the canonical job representation theorem already implicit in the
   raw numerical acceptance, avoiding the duplicate 2.5--3.1-second check;
2. determine whether root canonicality can be inherited from authenticated
   inputs or the known outer box, avoiding a second 2.9-second traversal;
3. exercise the same proof adapter on larger real segments with preparation
   amortized; and
4. only then run the reflected path over the complete 875-cell case and
   compare its final theorem and throughput with the preserved native control.

No release claim is made from this four-cell result. The complete native run
and direct Flyspeck action-184 run remain the authoritative active long runs.
