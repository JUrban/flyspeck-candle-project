## Experiment

The v3.03 profile measured a 10.072-second increment when all 44 fixed-class
instructions were repeated. This probe divides them into the two actual
subclasses in the case-10173 source program:

- 22 compiled polynomial pushes; and
- 22 fixed outer-algebra instructions (14 additions and 8 multiplications).

For a selected subclass, each authentic instruction is computed once as a
discarded duplicate before the unchanged checker instruction runs. The
matched control executes the same classifier without the duplicate. All calls
use the same 128 authenticated case-10173 cells. The duplicate expression is
syntactically inside the selected conditional, so unselected instructions do
not evaluate it.

## Result

| Mode | Run 1 | Run 2 | Mean |
|---|---:|---:|---:|
| Polynomial control | 24.368 s | 19.641 s | **22.005 s** |
| Polynomial duplicate | 32.839 s | 30.722 s | **31.780 s** |
| Outer-algebra control | 22.966 s | 21.255 s | **22.111 s** |
| Outer-algebra duplicate | 21.257 s | 23.270 s | **22.264 s** |

The within-class repeated-step increments are:

- compiled polynomial pushes: **9.776 seconds**;
- outer additions and multiplications: **0.153 seconds**.

Normalized descriptively per selected instruction and cell, those increments
are about 3.47 ms for a compiled polynomial push and 0.054 ms for an outer
algebra instruction. The outer increment is much smaller than ordinary
between-run variation and is therefore indistinguishable from timing noise.

The two fine-class increments sum to 9.929 seconds, close to but not exactly
the 10.072-second coarse fixed-class increment from v3.03. As with the
nonlinear split, these are diagnostic paired deltas rather than an exact
additive profile: classification changes equation paths, while repeated work
can change allocation and GC behavior. The robust result is that compiled
polynomial pushes account for essentially all measurable current fixed-class
cost; fixed outer addition and multiplication do not present a useful
optimization target in this workload.

Every call accepted all 128 cells, returned a closed result, and left the axiom
inventory unchanged. Peak sampled RSS was 17,982,344 KiB.

## Plan consequence

This closes the cheap discriminator proposed in v3.04. Within the established
current checker, the two numerically material targets are now:

1. compiled polynomial evaluation, which accounts for nearly the entire
   fixed-class increment; and
2. shared nonlinear Taylor machinery, where square root is the largest
   aggregate user only because it occurs most often.

The next implementation experiment should therefore address polynomial
evaluation or a primitive shared by polynomial and nonlinear interval work,
not the already-cheap outer add/multiply layer. It must preserve the existing
enclosure tightness, 16-leaf certificate coverage, closed final theorem, and
compact proof handoff. The genuine verifier integration remains the deciding
test after any focused candidate succeeds.
