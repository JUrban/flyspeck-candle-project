computation was used.  The final clean builds were:

representation mismatch or a slow genuine computation.

## Remaining route to the first theorem

1. State and prove a stack relation suitable for a whole ordinary
   polynomial-program trace.
2. Compose the six local bridges over the authenticated genuine
   167-instruction program and prove the exact final runtime state denotes
   the semantic program result.
3. Prove the complete checker verdict from that result and the already
   accepted certificate data.
4. Apply the established analytic/checker soundness chain to obtain the
   original Flyspeck theorem.

The main uncertainty has therefore moved from the semantics of an individual
production instruction to the size and shape of trace composition.  That
composition will first be probed on short real prefixes and built
incrementally; an hour-scale run is not justified until those bounded proofs
are green.
