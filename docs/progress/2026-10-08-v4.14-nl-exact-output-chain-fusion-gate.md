## Decision and broader interpretation

Exact-output chain fusion is rejected as a large-gap project.  Native source
dispatch and transient `TaylorResult` sequencing contribute about one percent
on this complete genuine batch.  No proof work is justified for a fused
instruction that merely calls the same completed operations.

The historical approximately 340-times number must remain explicit but also
properly scoped.  It is the starting generic case10173 fixed-scale versus
specialized-C++ comparison, not a measured residual for the current
case16594 lane.  Controlled native work on case10173 reduced that fixture's
optimized residual to about 1.35 times.  The current matched case16594 result
instead has an approximately 24-times verified-Candle versus exact-native
execution gap and no like-for-like historical specialized-C++ denominator.
The ratios therefore remain distinct and must not be multiplied.

The orders-of-magnitude objective still applies to total Flyspeck nonlinear
verification.  The evidence now rules out three easy explanations for the
current case16594 batch:

- parsing and number conversion are about 3% of complete checked time;
- source-chain dispatch/materialization is about 1% of exact-native time; and
- the held-axis native graph and arithmetic changes together contributed
  about 3.7 times, not orders of magnitude.

The next substantial numerical candidate must therefore do less enclosure
work per box while preserving or improving bound quality.  It should port a
faithful specialized dihedral derivative/Hessian data flow, retain necessary
intermediate tightening, and first run under the current exact dyadic
arithmetic.  Only an all-875 material winner should be crossed with the
padded-hardware discriminator and considered for a reusable proof.

In parallel, the current verified-execution result justifies continuing the
general fixed-layout checked-word executor work.  The six accepted delta
roles remain the only bounded specialization proof packet; this rejected
fusion adds no new proof obligation.
