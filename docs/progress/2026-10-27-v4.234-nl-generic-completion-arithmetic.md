## What was proved

`bounded_taylor64_complete`.  CakeML branch
`codex/fast-nl-data-dispatch-v1` now proves the low-level arithmetic contracts
needed to reason about that routine:

1. exact integer refinement for the executable scale-2^81 center-value
   embedding and scale-2^41 linear-error embedding;
2. exact quotient/remainder refinement for the 192-bit division by 2^81;
3. lower and upper directed-rounding bounds for the signed 192-bit value
   path;
4. the corresponding scale-2^40 embedding and directed-rounding bounds for
   the signed 128-bit gradient path;
5. end-to-end raw enclosure theorems for one completed value interval and one
   completed gradient-row interval; and
6. a generic object-q theorem showing that the executable absolute upper
   bound of any covered interval also upper-bounds the exact rational absolute
   value used by the object Taylor contract.
