## Result

Candle commit `da228838` adds and proves a reflected batch interface in which:

- one authenticated analytic source program remains fixed;
- every job supplies its own whole-box square-root hints, center hints, and
  exact box as ordinary data;
- the computation checks the hint shapes and exact permitted patching, runs
  the fixed-outer Taylor checker, and returns one acceptance flag for the
  batch; and
- the general soundness adapter turns that flag into closed source theorems
  without adding an axiom or changing a theorem interface.

This removes the earlier requirement that all jobs in a batch share one set
of whole-box hints. It is the bounded stable-program/data-only-certificate
interface proposed in the 2026-09-28 architecture response, not yet the
complete tree-certificate checker.

## Interpretation

The experiment validates the proposed data boundary, but it also narrows the
performance diagnosis:

- repeated evaluator startup is not the remaining large cost; the compute
  phase stays approximately linear at 2.1--2.3 seconds per box;
- host job encoding/preparation is about 0.26--0.29 seconds per box in the
  larger batches;
- per-leaf source extraction and final theorem handoff still cost roughly
  0.7--0.8 seconds per box; and
- one accepted batch flag by itself does not deliver a major workload-level
  speedup while the adapter still reconstructs one theorem per leaf.

The next architectural boundary should therefore combine the per-job
numerical verdict with checked exact split-tree topology and return one root
theorem. That can remove the measured per-leaf post-accept work. It will not
remove the approximately 2.1-second numerical cost per accepted box, so
measured numerical representation work remains necessary in parallel.
