## General soundness boundary

The new proof establishes an invariant over the active root stack: every box
on the stack satisfies the source-level `m_cell_pass` predicate.

- A leaf preserves the invariant by the existing universal analytic checker
  theorem and the independently proved raw-job acceptance theorem.
- A glue preserves it by the exact rational split relation and the existing
  vector split/glue theorem.
- A successful run that consumes every job and leaves exactly one root box
  therefore yields one `m_cell_pass` theorem for that root.
- The existing authenticated source reifier then rewrites that result to the
  original Flyspeck formula without new assumptions.

The soundness proof is dimension-polymorphic. The proof-producing adapter is
specialized to dimension six and supplies proved reductions for its closed
small-numeral guards. This makes rewriting select one branch at a time rather
than materializing both sides of every conditional in a large certificate.
