## Corrected unit of projection

The previous 7,814 count is the number of explicit outer `Iarg_leaf` domain
pieces.  It is **not** the number of final nonlinear inequality records.  The
actual direct workload contains **23,242 serialized parameter records** over
812 source IDs.  A parameter record may be one of several prepared
inequalities associated with the same outer partition, as illustrated by
case 16594: source `prep-8293089898` has parameter index 264 inside a
333-record parent, while its outer `iargs` tree has 111 leaves.

This distinction was detected before committing or timing the provisional
sample.  The sample now uses the real `(source_id, parameter_index)` identity.
The outer 7,814-leaf inventory remains useful for production path depth and
historical C++ coordinates, but it is not used as a certificate identity.
