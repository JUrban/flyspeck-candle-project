## Decision and next boundary

The shared-jet path has now succeeded on the same real formula and every real
leaf box used by its legacy certificate.  There is no present evidence for
investing in smart symbolic differentiation: the 43-program expansion remains
a negative comparison path, while one shared program gives useful batch
throughput and the desired language-wide analytic theorem.

The next bounded milestone is a complete reflected proof of this genuine
inequality.  The implementation will bridge each reflected leaf theorem into
the existing certificate result type and reuse the established 15 split/glue
steps to assemble the original root theorem.  Only after that integration
works is it useful to optimize the theorem-handoff cost or broaden expression
coverage.
