## Fixed graph, changed normalization

This experiment holds the authenticated formula, 4,173 boxes, derivative
graph, Taylor handoffs, long-double representation, operation counts, and
scale fixed. Both lanes execute 4,231,422 evaluation quotients and 2,220,036
interval products. Exact-zero product skipping is disabled so that numerical
rounding cannot change the executed graph.

The control rounds every quotient to the fixed grid and pads it by one unit.
The diagnostic lane simply divides in hardware. The latter is explicitly
untrusted: it is neither outward rounded nor a candidate implementation, and
it provides only a lower-bound timing for removing normalization work.

## Decision

The unsafe lower bound still takes 3.075 times the 0.082490265-second
historical specialized C++ batch. It is also close to the separately measured
0.251070965-second exact int128/dyadic deferred-leaf lane. Thus neither fixed
grid normalization nor directed quotient rounding plausibly contains the
remaining multi-fold improvement on this fixture. Building and proving a full
outward hardware-endpoint backend is not the next investment.

A preliminary same-source run of the source-derived historical graph under
the same unsafe arithmetic was only about 2% faster than the generic graph,
so that formula substitution also does not expose the missing factor by
itself. The next bounded factorial test changes endpoint width/layout while
holding the unsafe graph fixed: compile the same diagnostic with hardware
`double` rather than `long double`, and compare both the generic and historical
graphs. This mirrors the historical verifier's scalar type more closely and
will tell us whether the remaining gap is representation/layout or requires a
more faithful whole-checker/dataflow port.

No proof target changes from this diagnostic. The center-tangent and deferred
leaf mechanisms remain reusable pieces, but proof work waits for a materially
faster complete candidate that passes exact outward acceptance and then a
multi-certificate gate.
