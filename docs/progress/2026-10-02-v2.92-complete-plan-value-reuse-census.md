There is therefore no useful whole-cell or whole-vector interning opportunity:
every complete vector is different. Exact pair tables are materially more

- box/center intervals show **3.53x** value reuse;

The measured result supports an indexed compact encoding as a bounded backup
if the larger heap still proves inadequate or leaves excessive preparation
cost. It also argues against spending effort on whole-vector deduplication.
The current architecture is not being redesigned before the unchanged
larger-heap experiment answers its narrower capacity question.
