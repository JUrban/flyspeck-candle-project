## Payload and encoding differences

The routes cover the same genuine case-16594 expression, 875-cell subdivision
and 1,749-item topology, but their payload bytes are intentionally not the
same:

- stock reconstructs HOL `cval` jobs from the authenticated rational
  fixed-outer-variable plan inside the restored state, evaluates the ordinary
  compiled analytic program, and returns a kernel theorem;
- fast parses authenticated flat external data, uses fixed `2^40` words,
  source-rounded outer boxes with one radius unit of padding, plan codes for
  the six proved delta specializations, and compact cell/token/job encodings;
  it returns the proved callback verdict, not yet the HOL theorem; and
- the G7 transport must prove that an accepted packed replay denotes the
  canonical original function and supports the same root theorem.  That
  structural conditional subsequently passed and is committed at Candle
  commit `d458eeed`; its accepted runtime-verdict premise is deliberately not
  claimed by this benchmark.

The benchmark therefore measures two semantically intended routes on the same
case and topology, not byte-identical evaluator inputs.  That distinction is
part of the route decision and must not be hidden.

## Controls, failures and caveats

The first source-only preflight, preserved as
`v3952-case16594-matched-stock-preflight-dev-001`, failed before computation
because the Candle state did not expose `Printf.printf`.  The benchmark source
was narrowed to `print_endline` phase markers.  The clean source-only preflight
`v3953-case16594-matched-stock-preflight-dev-001` then passed in 100 seconds
without starting `Kernel.compute`.

The host had transient load bursts during the run.  Most instantaneous samples
showed 95--98% idle CPU and no swap I/O.  One accidental repository search ran
for about 37 seconds on another core during stock run 1; it was stopped as
soon as detected.  This is disclosed because it can affect wall time.  It did
not share pinned CPU 110, and per-process CPU time is the primary result.
Stock run 1 is also the slowest member of the distribution, so the report does
not conceal the effect by reporting only an average.

All six `/usr/bin/time -v` records report zero swaps and exit status zero.
Every stock log contains exactly one final marker with 875 cells, 1,749 token
items, zero assumptions, zero axiom growth, and theorem digest
`8bb2c1bf3d1c1944d497c0da68b88207`.

## Decision boundary

This measurement rejects both the old pessimistic 1.70x ratio and any claim of
an order-of-magnitude production speedup.  For this case the current callback
has a reproducible roughly **3.6x recurring CPU advantage** and roughly
**3x lower peak RSS**.  The complete corpus projection, unsupported fraction,
and the cost of the remaining production integration remain necessary before
the owner chooses a route.  The structural G7 bridge is green, but the first
fast original theorem remains 0/1 because the actual runtime verdict is still
an explicit premise.  No G5P or G8 work is authorized by this benchmark alone.
