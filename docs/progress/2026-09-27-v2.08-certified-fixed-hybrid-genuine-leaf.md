## Updated assessment of the performance research note

The note correctly identifies several possible costs, but the evidence now
separates them more sharply.

### Covered and materially relevant

- **Rational normalization and GCD:** this is the strongest measured
  explanation.  Replacing rational polynomial blocks with outward-rounded
  fixed scale retains a 2.69x advantage inside the complete genuine checker,
  and the corresponding soundness path is now proved.
- **Repeated evaluator setup:** the existing aggregate/batch boundary already
  allows many boxes to share one evaluator entry.  It remains worth measuring
  at larger scale, but no new persistent evaluator architecture is needed for
  the next experiment.
- **Unnecessary returned intermediates:** prior compact-result versus
  aggregate-only runs were essentially equal at the tested boundary.  Large
  returned diagnostics are therefore not the leading current explanation.
- **Proof-producing preparation:** source reification, program authentication,
  and box correspondence do construct theorems, but their 8.793943-second cold
  cost is separated from recurring numerical checks and can be shared.  The
  accepted numerical certificate is now consumed by one general soundness
  theorem rather than reconstructing arithmetic proofs for intermediate
  values.

### Relevant but not yet demonstrated as dominant

- Constant/zero fast paths, Hessian-only operations, endpoint-product reuse,
  sparse jets, and symmetric Hessian storage are plausible reductions.  They
  should be tested only after a larger hybrid batch shows which operations and
  data sizes dominate.
- Fixed scale currently accelerates polynomial blocks while square root,
  reciprocal, arctangent, and their domain guards retain exact rational
  semantics.  A larger expression mix can reveal whether one of those
  remaining operations becomes the next bottleneck.
- Interpreter specialization or verified compilation could matter if the
  larger fixed batch remains far behind an ordinary numerical baseline, but
  the present measurements do not yet isolate evaluator dispatch from
  arithmetic cost.

## Next discriminating experiment

Build a theorem-authorizing fixed-hybrid batch over distinct genuine boxes,
preferably at 1, 8, and 64 cells.  Charge source/program preparation once and
measure separately:

1. box/variant encoding;

If recurring compute still dominates, add counters or one-change A/B tests for
the remaining rational operations and Hessian representation.  If theorem
handoff or box encoding dominates, optimize that measured boundary instead.
This preserves the general soundness proof and the amortization picture while
avoiding speculative changes to the verified numerical architecture.
