# v4.180: literal six-coordinate source prefix

Date: 2026-10-20 UTC

Status: **DEVELOPMENT / NON-RELEASE**

## Headline

The authenticated actual-operand contract now proves registered evaluation of
the complete six-coordinate head prefix: six unchanged literal
`candle_cv_fs_poly_program` variable calls and their six following unchanged
`candle_cv_fsn_result_sqrt` calls.  The proof obtains each result from the
already checked decimal witness and composes the entries recursively; it does
not repeat the generic numerical calculation.

This closes the first recursive source-assembly boundary in the implementation
plan.  It does **not** yet cover the coefficient/term program sequence, result
multiplication, a complete arbitrary job, packet/recursive-job authentication,
default-clock kernel dispatch, or the literal original Flyspeck theorem.  The
count of fast-route literal original theorems therefore remains **0**.

semantics to the Taylor result encoding.  Its specialized theorem consumes the
same decoded center box, radii, coordinate index, six-dimensional shape, and
zero-Hessian witness used by the corrected square-root contract.

The new recursive prefix theorem then decomposes the canonical actual-operand
contract once per coordinate.  At every step it proves:

1. the literal variable program returns the exact Taylor state authenticated by
   the decimal contract; and
2. the literal square-root operation on that exact state returns the
   authenticated fast decimal result.

`registered_case10173_actual_six_coordinate_eval_prefix` instantiates the
recursive theorem at six coordinates starting from index zero.  Both source
calls use the historical equation set and are stated uniformly above their
proved local clock thresholds.

## Verification and diagnosis

The focused HOL build completed successfully and exported all three new helper
theorems, the recursive soundness theorem, and the six-coordinate corollary.
The final theory-builder pass reported 11.6 seconds; repeated Holmake startup
and dependency scanning dominated the roughly one-minute edit-loop wall time.

Two proof-script failures were local representation issues, not numerical or
semantic counterexamples:

- the recursive definition initially needed explicit grouping so its tail was
  part of the successful clause; and
- the square-root handoff needed the Taylor-row object encoding unfolded before
  `from_cv` normalization could identify it with the registered source input.

No qualified Great100 evidence and no Flyspeck source theorem were changed.
