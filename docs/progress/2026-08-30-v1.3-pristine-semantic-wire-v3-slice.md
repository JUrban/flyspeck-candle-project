# Pristine semantic wire v3 pure slice (2026-08-30)

## Implemented boundary

This change implements only the accepted design's disjoint raw-protocol v3
migration and pure semantic decoder.  The plan, request, transcript, native
closure, source-rederivation and candidate identifiers now use schema/kind v3,
and all six outer marker names use the disjoint `V3` namespace.  The embedded
LP inventory and success objects remain their separately named schema 1.

The raw plan and request each require the exact top-level fields
`retained_stdout_max_bytes = 536870912`,
`retained_stderr_max_bytes = 0`, and one canonical safe absolute
`retained_input_artifact_root`.  Request validation requires exact JSON value
equality to the plan for all three fields.  The five-input source parser checks
the immutable byte types and caps before hashing, decoding, or line splitting.

`decode_semantic_v3_bytes` accepts only the ten exact
`CANDLE_PRISTINE_DIRECT_SEMANTIC_V3` lines.  It enforces the four theorem,
post-state, four dependency, and terminal order; exact nonce, indices, names,
boundary and counts; lowercase serialized hex; canonical decimal fields;
exact `candle_s1_field` and node framing; theorem/kernel reconstruction;
list cardinalities; empty hypotheses; and raw shared-global-axiom equality.
It hashes decoded serializations and returns only the strict nonce-free common
semantic projection after the existing direct projection validator accepts it.
Every public parser operation first revalidates the supplied plan/request and
rebinds the project root plus executing parser, pristine-protocol and
direct-protocol bytes to the trusted loader activation.  Semantic projection
construction additionally requires the plan-bound validated raw transcript and
native closure; it derives the serializer path and SHA-256 from the exact final
native serializer event only after that event equals plan authority content.

Every framed length and child count is checked lexically with at most nine
digits, bounded by 536870912, and converted through `OutputProtocolError`.
The upper bound is compared lexically before integer conversion.  A declared
payload length must fit the remaining bytes before any payload extraction.
Before constructing a child range or iterating, node decoding requires
`child_count <= remaining_bytes // 2`.  The hostile fixture with child count
100000000 and no remaining bytes exercises that exact pre-loop rejection.

## Deliberate fail-closed limits

The ten-line state machine is not yet integrated into the full stdout parser.
The parser continues to reject semantic markers and returns an explicitly
incomplete schema-v3 source rederivation with null semantic projection,
semantic-completion observation and cross-runtime coverage.  It is marked
`not-authenticated`, contains no candidate, and keeps approval, promotion,
PFT, S2 and S3 false.  Its diagnostic kind is disjoint from the reserved final
`candle-flyspeck-pristine-direct-raw-source-rederivation-v3` kind.

Standalone raw-candidate validation, canonical candidate decoding/consumption,
value-only bundle validation, and pair validation unconditionally reject.
The canonical candidate entrypoint rejects immediately, before JSON decode,
canonicalization, nested dependency validation, or mutable-byte inspection.
They cannot succeed until the descriptor-rooted collector, capture envelope,
coverage adapter, pending-candidate publication and terminal postflight exist.
No request generator, collector, candidate, comparison descriptor, live pilot,
approval or workload is added by this slice.

A same-shape substitution of a well-formed 32-hex dependency digest remains an
honest passive-parser limitation: it changes the derived raw projection and is
not rejected or called authenticated.  Later held-process authentication and
two independent reference comparisons must establish its provenance.
