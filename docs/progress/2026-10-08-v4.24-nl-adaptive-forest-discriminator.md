## Complete genuine-forest result

The fifth nonlinear sibling's authenticated state exported 20 nontrivial
function-1 roots and their exact 11,718-node split topology.  A development
reconstructor reproduces Flyspeck's six-digit base-200 upward-rounded split
center, not an exact rational midpoint.  Every one of the resulting **5,869
terminal boxes matches its independently exported HOL/Flyspeck reference
box exactly**.

The native discriminator evaluated every node, replayed each lane's actual
pruning decisions, and required every reached leaf to have a strict negative
upper bound.  Explicit numerical domain failures at broad ancestors mean
"must subdivide"; domain mismatches, shape drift, and unrecognized failures
remain fatal.  The padded development backend also counts an unavailable
hardware representation as a forced subdivision.  It never borrows an exact
answer, and a failure surviving to a terminal leaf rejects that lane.

Holding the historical mathematical route and its 1,344-node accepted search

## What this says about the two larger gaps

The result separates mathematical work from arithmetic on the same genuine
forest:

- changing the enclosure algorithm, with checked exact arithmetic held fixed,
  gives the 6.890-times complete-batch improvement through pruning;
- changing arithmetic, with the accepting historical algorithm and node set
  held fixed, gives another 1.835-times numerical improvement.

It does **not** cancel or redefine the older approximate 15-times
Candle/native and 340-times generic-fixed/specialized-C++ measurements.  Those
were obtained on case 10173 with different data and timing boundaries.  They
remain explicit architectural reference problems.  This new result instead
shows that a faithful low-work enclosure is a large reusable lever on another
real Flyspeck case, and that arithmetic remains a smaller but material second
axis.

The padded lane is an untrusted performance discriminator, not a proposed
proof backend.  Its generic terminal failures are useful evidence against
formalizing that approximation as-is.  The immediate proof target remains
checked outward arithmetic plus a generally sound specialized instruction.

## Bounded proof and performance plan

The historical-dihedral proof gate is now open, but its scope stays bounded:

1. Freeze the exact sign-directed historical formula and its three authenticated
   permuted delta-dihedral source-DAG motifs.  Recognition must check the full
   source identities and permutations; unrelated expressions fall back to the
   generic evaluator.
2. Prove one reusable interval/jet soundness theorem for that instruction,
   with explicit delta, `U`, denominator, square-root, arctangent, gradient,
   Hessian, and domain hypotheses.  This is an instruction theorem, not a
   separate calculus proof for the current expression.
3. Extend the universal evaluator invariant so a recognized instruction and
   the existing generic source-DAG steps share the same jet contract.  Reuse
   `candle_q_dim_poly_jet_whole_box_accept_sound` for the analytic handoff.
4. Finish the existing source-DAG miss/refinement induction and compact verdict
   theorem.  The final certificate checker should return one compact accepted
   verdict rather than materializing per-node arithmetic theorems.
5. Add streaming forest replay with the proved rule: an unresolved domain
   subdivides, a negative bound prunes, and every surviving terminal must
   accept.  Measure preparation, traversal, computation, theorem handoff,
   required repeats, memory, and reusable setup separately.
6. Run the instruction on a second genuine expression family before treating
   the current 6.89-times result as a workload-wide estimate.

Proof work on the padded backend is deferred.  After the exact specialized
instruction is green, the distinct Candle/native target is a proved checked-
word executor with narrow stored endpoints, wider checked products and
accumulators, explicit overflow data, and exact fallback.  The current padded
run supplies a performance ceiling and failure fixtures, not its correctness
argument.

The next numerical discriminator is therefore small: a streaming version of
this same accepted forest, followed by one independent real family using the
same dihedral instruction.  No further local dihedral variants are planned
before those integration tests.
