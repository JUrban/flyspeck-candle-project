The reflected center and gradient are slightly tighter. The whole discrepancy

## Decision and next numerical boundary

The reflected split proof is retained as a complete correctness reference, but
it should not be replayed across the remaining 1,060 action-296 leaves in its
current form. That would spend hours confirming a numerical architecture whose
first matched leaf is already much slower than legacy.

The next bounded target is to make the **original unsplit leaf** return a
negative computed upper bound while retaining the universal source theorem and
computed theorem handoff. Work should focus on tight Hessian production:

1. localize the forward-jet dependency loss inside the analytic composite;
2. prototype compact verified derivative/check data evaluated entirely inside
   `Kernel.compute`, with preparation charged once and correspondence checked
   by a general theorem;
3. consider externally prepared sparse derivative plans only as untrusted data
   whose exact relation to the authenticated analytic AST is cheaply checked;
4. rerun this exact leaf and require a negative unsplit bound before a
   multi-leaf or multi-inequality batch.

This evidence changes the earlier decision to defer derivative-oriented work
for supported expressions. The shared-jet path remains attractive for compact
source authentication and fast center calculations, but its current
whole-box analytic Hessian is not tight enough for the live action-296
workload. A hybrid or verified compact-derivative Hessian path is now justified
as a bounded prototype; recreating 43 host-expanded proof programs per leaf is
not.
