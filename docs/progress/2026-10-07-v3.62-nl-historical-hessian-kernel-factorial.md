## What this says about the two performance gaps

The original approximately 340-times native-fixed-scale/specialized-C++ gap
and the encoded Candle/native gap describe different boundaries.

Native factorials already show that, on this fixture, changing exact endpoints
to padded outward doubles accounts for only 1.628x recurring time and changing
the tested generic graph to the direct graph under the same double arithmetic
accounts for only 1.087x.  The best untrusted native direct plan has therefore
removed most of the original 340-times starting gap.  More scalar or graph
micro-tuning in native code is not the highest-value next step for this
fixture.

The exact-output reflected measurements now put the remaining encoded boundary
at 13.9--33.6x for the isolated historical derivative stages, depending on the
amount of work per call.  The full second-order workload amortizes evaluator
and theorem overhead much better than the lighter first-order workload.  This
is evidence for a compact whole-operation instruction, but it is not an
orders-of-magnitude end-to-end result.

## Bounded integration and proof gate

No standalone soundness proof for this case-specific implementation starts
yet.  The next packet is deliberately bounded:

1. splice the complete historical angle operation into the existing
   case-10173 reflected checker while retaining the current sealed roots;
2. measure the genuine 128-box whole-checker result, including reusable
   preparation, computation, theorem handoff, bound quality, and all-box
   certificate acceptance;
3. compare program size, traversal/allocation behavior, and GC with the current
   checker so that an apparent local win cannot hide work moved elsewhere;
4. only for a material whole-checker winner, move roots inside the computed
   operation and attempt all 4,173 boxes; and
5. require a second certificate family before proving one universal
   source-authenticated complete-box instruction theorem.

Failure at step 2 stops the historical specialization proof.  Success advances
the proof because the executable graph is now exact-output matched and small
enough to be a credible compact instruction.

For the larger remaining gap, the concrete direction is evaluator-facing:
batch compact operations, keep intermediate intervals as data, return only the
verdict/bounds needed by the general soundness theorem, and avoid rebuilding
the same encoded traversal and theorem-shaped intermediates per leaf.  The
native controls remain useful to reject algorithms with excessive numerical
work, but complete-certificate Candle time and acceptance are the deciding
measures.
