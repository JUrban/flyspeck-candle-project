## First executable tame-graph slice

The tame-graph plan now has a proof-producing Candle implementation below the
archive and enumeration layers. The new module defines:

- logical encoders for a face (`num list`), fgraph (`num list list`), and
  explicit vertex map (`(num#num) list`);
- total decoders plus closed round-trip and injectivity theorems for all three
  encodings;
- strict executable validation of list shape, numeric vertex shape, vertex
  range, per-face distinctness, map-entry shape, source/target range, and
  source/target injectivity; and
- all-variable characteristic equations suitable for `Kernel.compute`.

The list terminator is exactly `Cexp_num 0`. Nonzero numeric tails, pair-valued
vertices, malformed map entries, out-of-range vertices, repeated face
vertices, duplicate map sources, and duplicate map targets all return the
false cval. The validator does not use host exceptions as acceptance.

The proof module explicitly states its present boundary: it does **not** yet
establish canonical rotations or graph ordering, check graph isomorphism, bind
the nine triangle graphs to `tame_archive_lists`, or prove tame enumeration
completeness.
