## Question

The accepted native fixed-scale checker was still about four times slower than
the historical specialized C++ lane after source compilation, support-aware
jets, scale reduction, unchecked native arithmetic, and reusable square-root
preparation.  This packet asks whether fixed integer representation and exact
division, rather than the amount of derivative/Taylor work, account for that
remaining gap.

## Controlled experiment

The candidate uses the same 4,173 genuine certificate boxes, authenticated
program, scale `10^7`, prepared square-root certificates, operation graph, and
Taylor completion as the accepted native `int128` lane.  Only the endpoint
backend changes: integer-valued `long double` endpoints execute the graph, and
every division is padded outward by one fixed-scale unit.

This is deliberately untrusted development code.  It is gated by complete
acceptance and by empirical final-bound containment against the exact native
`int128` lane.  It is not evidence that floating-point rounding is sound.

Twenty warmed, order-balanced pairs produced:

| Lane | Preparation | Evaluation | Complete batch | Accepted |
|---|---:|---:|---:|---:|
| Native `int128` | 0.343606176 s | 0.324682706 s | 0.668288882 s | 4,173/4,173 |
| Padded `long double` | 0.303689110 s | 0.329609298 s | 0.633298407 s | 4,173/4,173 |

The candidate is 1.5% slower in recurring evaluation.  Its cold complete batch
is only 1.055 times faster because preparation is cheaper.  All 4,173 final
bounds contain and are wider than the exact native results; none is tighter.
The median widening is `8.26e-5`, the maximum is `5.979e-4`, and all boxes
remain accepted.  Candidate evaluation is 3.996 times the historical

## Decision

No floating-point endpoint proof or integration work is justified.  The
original approximately 341-fold native/specialized ratio records where the
architecture began, while the current accepted native lane has reduced that
specific ratio to about four.  Hardware endpoint arithmetic does not close the
remainder.  The still-separate approximately 15-fold encoded-Candle/native
measurement will be repeated only after the numerical operation graph is
settled.

The next bounded discriminator changes derivative/enclosure work while keeping
the accepted fixed arithmetic and full-certificate gates fixed.  It will port
the historical sign-directed path in measurable stages: `setDeltaFull`, then
`setDeltaX4` and derivative square root, then `setU126`/`setU135` and
`setDihedral`.  Each stage must report total cost and bound quality.  The
rejected dense specialization receives no bespoke proof; formal integration
starts only if the complete low-work native route preserves 4,173/4,173
acceptance and wins materially end to end.
