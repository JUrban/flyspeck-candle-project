# Direct runner controller provenance — 2026-08-28

This interim report records closure of the v1.3 host-controller provenance
gate. It does not claim a compiled Candle pass, a completed Flyspeck stratum,
S2, or S3. The verified CakeML bootstrap is still active, and the independent
PFT export remains an oracle lane only.

## Reviewed commit

The clean Candle integration branch `codex/flyspeck-v13-candle-integration`
is at `0788eaaaed32cd7967ce4eab3dc8ab551f4ea13e` (`test: bind direct
stratum controller provenance`). The runner now authenticates the controller
that selects and launches every cumulative Flyspeck stratum, rather than only
the payload files that controller consumes.

The exact runner, planner, runtime-lock helper, and CakeML artifact-provenance
source bytes are privately loaded from source and compared with their blobs at
the linked Candle commit. Cached bytecode is not accepted as an execution
source, and Git index flags that could hide drift on these files are rejected.
Every Git invocation uses the same seven-key environment and explicitly
disables fsmonitor, the untracked cache, and preload-index behavior.

Direct execution is restricted to `/usr/bin/python3 -I -S` with the pinned
Python 3.12.3 process image. Imported/module startup, optimization, warning,
unbuffered-I/O, and arbitrary `-X` modes are rejected. The exact files for the
Python executable and base ELF, `/usr/bin/git`, `/usr/bin/readelf` and its
resolved target, `/usr/bin/ldd`, and `/usr/bin/patch` are copied into the
attempt snapshot and reauthenticated during postflight.

Snapshot and attempt schemas are version 2. Attempt construction uses a
nonce-bearing ownership marker and recorded directory device/inode so a losing
same-path contender cannot delete another run. Output symlinks are rejected.
SIGINT and SIGTERM handler state and the original thread mask are restored on
exit; after the child is reaped, those signals are blocked across resource
collection, log hashing, postflight, and the final atomic receipt. A pending
interrupt makes the attempt fail rather than leaving a false successful
receipt.

- 15 CakeML artifact-provenance tests.

The broader static suite also passed before the commit: 187 Python unit tests
plus the 25-case OCaml Num oracle. A final independent full static rerun is in
