## Research-note assessment

The source observations in
`docs/advice/Candle_NL_Performance_Research_2026-09-25.md` are useful, but the
64-box measurement now separates the leading costs more sharply:

- General rational normalization and GCD work is a measured primary cost in
  the current reflected polynomial path.  Replacing it with reflected signed
  fixed-scale arithmetic reduced the recurring 64-box computation from
  105.14 seconds to 13.10 seconds on the repeat run, an **8.03x** speedup.
- Shared source preparation (4.54 seconds) and box setup (15.67 seconds) are
  material cold costs, but amortizable.  They do not explain the recurring
  arithmetic gap.
- Compact verdicts and internal batching are already used by that benchmark;
  all 130 checked full results (the two single-box controls plus 128 streamed
  box results) matched the rational backend exactly.
- Constant-node completion, unused projected jet components, repeated
  endpoint products, and proof-producing untrusted hints remain credible
  follow-up targets.  They should be profiled after the fixed-scale path is
  proved far enough to avoid optimizing the superseded fraction-heavy path.
- Repeated evaluator compilation remains relevant for small calls, but the
  64-box internal batch demonstrates that it can be amortized.  A persistent
  compiled context is therefore not the next proof-critical change.

The discriminating experiment supports the note's fixed-point recommendation
without implying that every source observation is a measured bottleneck.

## Remaining soundness path

This is not yet a release checker.  The remaining reusable proof route is:

1. lift raw fixed-scale multiplication and directed rounding through interval
   multiplication;
2. lift list, matrix, Taylor-sum, first-jet, and result-completion operations;
3. prove the postfix polynomial interpreter invariant;
4. connect its converted result to the existing universal analytic/Taylor
   soundness theorem;
5. rerun the complete genuine 16-leaf certificate proof and compare the
   matched legacy/reflected timings.

The next optimization experiment should be chosen from a profile of that
proved path.  The strongest current candidates are sparse/constant handling
and avoiding unused full-jet components; GCD-fuel sharing has much less value
inside the new backend because its hot path deliberately avoids GCDs.
